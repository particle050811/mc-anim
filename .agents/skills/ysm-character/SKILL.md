# 用 YSM 制作角色

- 先区分**角色设定**和**做法参考**。《亚波伦不放水》的人物来自 D 版 AI 封面和同版三视图；鲸鱼娘只说明要用多边形，不用它决定眼睛、发型或神态。把设定图和实模按同一眼距并排，再对照侧面与全身。
- 打开可编辑包里的 `ysm.json`，按 `files.player` 找几何、动作、贴图和默认皮肤；不要猜文件名。作者视频不等于取得源包。不解包加密 `.ysm`，不把其他作者的角色换进正片。
- 用 Blockbench 的基岩几何与 YSM 工具编辑；保留骨名、pivot、父子关系和每面 UV。俯视、正面与转脸都要能读出发束厚度和脸型；不要用光滑私有曲面或平面贴色替代原生几何。
- 《亚波伦不放水》的出包、改模、改舞和导回见 `作品/亚波伦不放水/制作/ysm/README.md`。严格出包必须无替代；读取导出后的 JSON 和贴图，验证与制作源一致。只有更改后再导回并核对才叫往返。
- 真人采样帧率、项目求值帧率、输出视频显示时钟分开查。动作验收看 `docs/动作体检.md`，出包不是通过动作体检的替代品。
- 先出一次正片模型的原生望远图，与用户指定参考放在一页；不要只对照上一版，也不要把项目渲染标成游戏实机。将文件、Blockbench 加载、Minecraft 实机分别报告。
