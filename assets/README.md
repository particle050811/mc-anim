# 资产

项目里所有要长期留着、反复用的二进制资产（模型、贴图、设定图、配音、音色、音效、配乐、地形……）都在这里登记，字节放在 Git 外的数据根。公开的和自己私有的都登记，区别只在「可见性」。

## 目录

| 位置 | 是什么 | 谁写 |
|---|---|---|
| `registry/<类>.toml` | 资产表，一类一个文件，一条资产一个 `[["资产"]]` | 人写 |
| `kits/<角色名>.toml` | 角色包：一个角色用到的资产 id、当前基准、生成链、代码位置 | 人写 |
| `src/` | 进 Git 的文字源（提示词 md、生成脚本 py、逐字稿 txt），清单在 `src/来源.toml` | 导入工具拷 |
| `冻结粗高度/`、`配乐分析/` | 进 Git 的小 json | 导入工具拷 |
| `资产锁.json` | id → 字节的 sha256、大小、在哪个库、后缀 | 导入工具生成 |
| `地形版本.json` | 地形区段包用哪一版、整包指纹 | 人写包名和版本，其余导入工具算 |
| `旧路径.tsv` | 旧项目路径 → 新 id（`git:` 开头是进了 Git 的文件，`terrain:` 是地形包） | 导入工具生成 |
| `待确认.md` | 许可、可见性拿不准、等用户定的资产 | 人写 |
| `tools/导入旧项目.py` | 从旧项目导入、核对 | |

数据根（默认是仓库同级的 `mc-anim-data/`，环境变量 `ANIM_DATA` 可改）：

- `store/<sha 前两位>/<sha256>`：可见性为 公开、提取、发布 的资产字节。
- `私有/<sha 前两位>/<sha256>`：可见性为 私有 的资产字节，和 store 分开，打包公开版时整个不碰。
- 随仓库发的作品（`<作品根>/字节/`，布局同 `store/`）：`anim render`、`still`、`film`、`studio` 开头把 store 里还没有的核过 sha 补进去，也可以 `anim assets seed`。
- 挂 Release 发的作品（`<作品根>/发布锁.json`）：`anim assets pull` 下载、核 sha，字节放进 `store/`、地形包放进 `terrain/`；render 这些命令开头缺了会提示。
- `terrain/<包名>/<版本>/`：地形区段包，版本是内容指纹。

库里的对象按内容寻址，只增不改（文件是只读的）；同一份字节被几条资产引用只存一份。

只有一部作品用的资产可以不进这里，登记在作品那一侧：`<作品根>/资产表/<类>.toml`、`<作品根>/资产锁.json`，格式和这里一样，`anim assets add` 按登记在哪一侧写锁。见 `docs/决策/0004-多作品.md`「作品资产表」。

## 资产表字段

```toml
[["资产"]]
id = "贴图/角色/九胡"
"类别" = "贴图"
"来源" = "提取:九胡模型@25b5e902b96f"
"许可" = "CC-BY-NC-SA-4.0"
"可见性" = "提取"
"旧路径" = "参考模型库/src/模型/角色/九胡.模型.png"
"说明" = "可选"
```

TOML 里中文键必须加引号（`"类别" = ...`），裸写会解析失败。

- **id**：`<类>/<分组>/<名>`。第一段和所在表的文件名一致。结构段用固定的词，实体名用中文。不能有空格和 Windows 不认的字符 `<>:"|?*\`，不分大小写也不能重名。
- **类别**：同 id 第一段。现有的类：体素、动作、动画、字体、数据、模型、碎块、网格、设定图、贴图、配乐、配音、音效、音色。动作 是从生物模型类字节码翻出的姿态程序（`docs/决策/0007-字节码翻译动作.md`）。
- **来源**：三种开头。
  - `提取:<配方>@<jar sha256 前 12 位>`：从游戏或模组 jar 按取材配方导出，可以重新导出。
    - 用到几个 jar 就把各自的前 12 位用 `+` 连起来，`anim check` 只认这种写法。`jars.toml` 登记的官方映射文件（如 `client-1.20.1-mappings`）也算一个。
    - 原版声音不在 jar 里，`@` 后面写 1.20.1 资源索引 `indexes/5.json` 的 sha256 前 12 位（`f59b7cfef660`），文件按索引里的 hash 取。
    - `网格图集` 是 mcai mesh 顺带导出的图集，`@` 后面是这张图集里实际出现的贴图所在的 jar（按旧项目 `工具/开源/图集配方.py` 逐格反查的结果）。
  - `手工:<说明>`：人做的，包括用户画的、录的，以及 AI 出图、AI 配音这类不可复现的成品。
  - `派生:<输入>+<工具>`：由仓库里的脚本从别的东西算出来，可以重跑。
- **许可**：SPDX 表达式。
  - 第三方照原许可，例如 `CC-BY-NC-SA-4.0`、`MIT`。
  - 自定义的有：`LicenseRef-Minecraft-EULA`（原版游戏文件）、`LicenseRef-Minecraft-Derived`（从游戏世界导出的网格、地形）、`LicenseRef-All-Rights-Reserved`、`LicenseRef-Adapted-Authorized`（小说改编，作者授权）、`LicenseRef-Photon-Shaders`、`LicenseRef-Origin-Unverified`（来源核实不了，原作者要求就撤下）。
  - 用户自己做的默认 `LicenseRef-用户保留`。
  - 拿不准写 `LicenseRef-待定`，同时在 `待确认.md` 加一行。
  - 一张图里叠了两种来源的，用 `AND` 连起来。
- **可见性**：
  - `公开`：可以随公开仓库发。
  - `提取`：公开版默认不带文件，由使用者从自己的 jar 按配方导出。
  - `发布`：可以单独打包发布（网格、碎块这类从游戏世界导出的大文件），默认不进公开仓库。
  - 例外：写了 `随仓库.toml` 的作品（现在只有 把回忆拼好给你），渲片用到的 `提取`、`发布` 字节随仓库发，放 `<作品根>/字节/`（用户 10-25 定，见 `docs/决策/0005-随仓库发字节.md`）。地形包太大，放 Release：写了 `随发布.toml` 的作品（现在只有 应力转动）用 `anim assets pack --上传` 发、`anim assets pull` 拉（`docs/决策/0006-挂Release发字节.md`）。
  - `私有`：只在本机和私有备份里，字节放 `私有/`。
- **旧路径**：旧项目里的相对路径（导入时读它）。新做的资产（`anim assets add` 入库的，如 `核对/*`）不写，导入工具照现有资产锁保留它们。
- **说明**：可选，写读者需要的一句，例如「现用」「被否掉的旧版」「用户 10-20 定照公开」。

## 资产锁

`资产锁.json`：`{id: {"sha256", "大小", "库", "后缀"}}`，键排好序，UTF-8，缩进 2。库是 `store` 或 `私有`。代码按 id 查锁，再到 `<数据根>/<库>/<sha 前两位>/<sha256>` 取字节；后缀给要按扩展名判断类型的地方用。

## 角色包

`kits/<角色名>.toml` 把一个角色常用的东西收在一起：做这个角色的镜头、改模型、补配音时先看这里。字段：

- `"角色"`：和文件名一致。另有 `"别名"`、`"出场"`、`"说明"`。
- `"渲染代码"`：画这个角色的组件文件（如 `库/角色/李樱.tsx`）；`"用法"`：最小用法示例（多行字符串，照抄进镜头改参数即可）；`"核对"`：哪个核对 Composition 和旧项目比过、结果。
- `[["基准"]]`：`"用途"`、`"资产"`（一个 id）、`"状态"`、`"说明"`。状态取：当前（以它为准）、旧版（留着给旧稿用，不要替换）、参考（量东西用）。
- `[["资产组"]]`：`"用途"`，再加以下几项：
  - `"资产"`：id 列表。
  - `"匹配"`：id 通配，如 `配音/?-李樱-*`。
  - `"文字源"`：进 Git 的文件路径。
  - `"说明"`。
- `[["生成链"]]`：`"产物"`、`"步骤"`、`"可复现"`（是 / 否 / 不确定）、`"核对"`（怎么验证过、为什么不能复现）。
- `[["代码"]]`：`"旧位置"`（旧项目里的文件）、`"新位置"`（搬进本仓库后的位置，代码还没搬时是计划）、`"状态"`（已搬 / 未搬，不写当未搬）、`"说明"`。

导入工具最后会核对角色包里的 id、匹配和文字源都找得到，渲染代码和「已搬」的新位置在仓库里。

## 导入和核对

```sh
python3 assets/tools/导入旧项目.py            # 导入：拷字节进库、拷文字源、拷地形，写锁和 旧路径.tsv，再全量回读
python3 assets/tools/导入旧项目.py --只核对   # 不拷不写，按现有资产锁回读库里和旧项目的每个文件
```

- 只用 Python 标准库（3.11+）。
- 旧项目默认在仓库同级的 `机械动力应力转动-AI漫画/`，环境变量 `ANIM_OLD` 可改；在 `mc-anim-wt/<名>/` 这样的 worktree 里跑，会自动再往上找一层。
- 可以重跑，已在库里的对象不重拷；旧项目只读，不往里写。
- macOS 上用 `cp -c` 写时复制，不额外占空间。

加资产：在对应的 `registry/<类>.toml` 加一条，再跑导入。拿不准许可的同时写进 `待确认.md`。
