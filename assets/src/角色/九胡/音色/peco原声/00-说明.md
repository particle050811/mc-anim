# peco 原声（酒狐的原始配音）

车万女仆模组（touhoulittlemaid 1.5.3）自带的 LittleMaid PECO 声音包，CV 秋野かえで，作者 tamemaru（原发 BOOTH「littleMaidMob俺得VoicePack３種」）。从 jar 的 `tlm_custom_pack/touhou_little_maid-1.0.0/assets/littlemaid_peco/sounds/maid/` 解出，转成 32kHz 单声道 wav，文件名加了 `peco-` 前缀（原名是模组的编号，如 `mode-furnace12` = 上一级的 `酒狐语音8s.WAV`）。

`00-转写-未校对.tsv` 是 Qwen3-ASR 机器转写，**没有逐条核对，不能直接拿去训练**。
