# 枯石大刀 新外观设计稿

纯文生图设计稿：为李樱的拔刀剑「枯石大刀」设计全新外观，推翻旧材质。主题源自 mcmod 资料——
「寄宿着衰老干枯以及爆裂的太刀」「衰枯之石所做之刀」，原型为怪物猎人碎龙太刀（爆砕の大刀）。

## 设计方向
- **形制**：大太刀，刀身修长微弧，气势凌厉，略带「龙太刀」的宽厚凶悍感
- **材质（衰枯之石）**：通体风化龟裂的深灰黑火山岩，裂缝密布、表面粗粝有剥落感
- **爆裂之力**：裂纹中透出炽热的琥珀橙色熔岩光，光沿裂缝蜿蜒流动；刃口为暗色火山玻璃，泛微弱赤红火光
- **配件**：粗粝石质刀柄缠绕发旧深色布绳；刀镡为带放射状裂纹的环状岩板；石质刀鞘，裂纹透出暗橙光
- **氛围**：枯败、衰朽、肃杀，却内蕴爆炸般的破坏力；周围飘散细微灰烬与火星
