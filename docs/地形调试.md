# 地形调试：按世界坐标标点、圈区域、看分级

用户 11-17 定：查地形问题不再在整帧上画屏幕网格、手划线找位置，一律按世界坐标。代码在 `engine/voxel/调试.tsx`，体素世界（`engine/voxel/世界.tsx`）自己挂上，各作品都能用。

都走试看参数 `REMOTION_ANIM_TRIAL`（`engine/core/试看.ts`），`anim still`、`anim bench`、`anim film` 的试看模式都认；没设时画面、着色器源码都和平时一样。可以和 `--tele` 一起用。名字和格式也在 `anim trial list` 里。

## 坐标

- 默认是**游戏坐标**（F3 里的 x y z），由体素来源的 `toScene` 换成场景坐标（导入地形、主世界地形都有）。
- 某一项写 `"场景": true` 就按场景坐标（Z 朝上，单位米）读，给没有 `toScene` 的来源用。
- 只给 `[x, z]` 两个数时贴地：高度取体素来源的地物顶（地面或树冠）。
- 开了任何一项，段里这一帧镜头的游戏坐标会打到终端（`[地形调试] 镜头 游戏坐标 …，前方 100 米 …`），定位置从它起算。

## 参数

| 名 | 值 | 做什么 |
|---|---|---|
| `标记` | `[{名, 位, 色?, 光柱?}]` | 照地图模组的路标：画面上一个点、名字和离镜头的距离，总在最前面（不被地形挡）。`光柱: true` 从这一点竖直往上打一道 1500 米的光（给数就是多高），远处也看得见 |
| `区域` | `[{名, 点: [[x, z], …], 色?}]` | 世界里的多边形（最多 8 个、合计 64 个顶点）：地形上描一道边，里面淡淡染成区域色 |
| `区域遮罩` | `true` | 配 `区域`：出遮罩图。地形落在区域里的像素写成区域色（原样，不过 AO、雾、云影），区域外的地形写纯黑；天空、云、人物、导出网格照常画（遮罩里认不出颜色的像素一律算「不知道」） |
| `级别遮罩` | `true` | 出级别遮罩图：每个地形像素写成它那一级的颜色（同 `按级着色` 的色板，原样，不过 AO、雾、云影），配 `区域遮罩` 那张图就能分级取平均 |
| `材质遮罩` | `true` | 出材质遮罩图：树叶（第 0 级镂空、粗级实心树叶）纯绿 `#00ff00`，实心（地面、原木）棕 `#804000`，花草黄 `#ffff00`，水蓝 `#0000ff`。量树冠盖住多少地面、树叶和地面各自的平均色 |
| `按级着色` | `true` 或 0～1 | 每个区段按级别叠一种颜色（`true` = 0.45）：第 0 级红、1 橙、2 黄、3 绿、4 青、5 蓝、6 紫（一格 1、2、4…64 米） |
| `世界网格` | 间距（米） | 地形上按游戏坐标每隔这么多米画线：x 白、z 青，每 5 道粗一倍；线距在画面上太密就不画。配 `标记` 读坐标 |
| `调试镜头` | `{位, 看}` | 只挪画面用的镜头，挑区段、定级别还照段里这一帧的镜头（等于把分级冻结在这一帧）。挪到交界正上方往下看、从侧面看各级怎么铺 |
| `加载视点` | `{位, 远?}` | 挑区段、定级别改按这一点算，四周都建（不按视锥剔），`远` 默认同体素世界；镜头不动。配 `调试镜头` 俯看一圈圈的分级 |
| `切级日志` | `true` | 不改画面，每帧往终端打一行 `[地形调试] 切级 {…}`：整段的帧号（`帧`）、镜头游戏坐标、离地多高、各级交界离镜头多远（`界`）、每一级画了几块、最近最远各多远、俯角几度（`级`），和上一帧比哪些区段换了级（`换`，`+`/`−` 级｜游戏 x｜z｜边长）。找「哪一帧、哪块地、从几级换到几级」用它，不用在画面上找交界 |
| `阴影日志` | `true` | 不改画面，级联阴影（`engine/light/级联阴影.ts`）有变就往终端打一行 `[阴影] {…}`：没取整的切分、各级到多远、着色里中远两级的交界、各级半径和一像素几米、中心。相邻几帧 `各级到` 第二个数来回变就是跳档 |
| `分级色调` | `{定级, 定级框, 场景, 真几何, 阴影, AO, 并色}` | 一小块地定成某一级、逐项关掉着色，量各级色调差，见下面「分级色调」 |

`调试镜头` 只在 R3F 画一帧的那一段把镜头换掉（同望远），所以组件渲染时读镜头的（挑区段、朝向）还是段里的；体素世界这时朝向全画（段里的镜头背面的也画）。镜头的视角、裁剪面照段里的。

## 例子

```sh
# 两块地描边、按级着色、城上打光柱
REMOTION_ANIM_TRIAL='{"区域":[{"名":"稀树草原","点":[[8000,-6000],[8500,-6000],[8500,-5500],[8000,-5500]],"色":"#ff7a00"}],
  "按级着色":0.35,"标记":[{"名":"城","位":[9000,-5300],"光柱":true}]}' anim still 6-飞越主世界俯冲边城 2017 --to-preview 工作-看一眼

# 同一帧出遮罩，量平均色只在遮罩里取
REMOTION_ANIM_TRIAL='{"区域":[…同上…],"区域遮罩":true}' anim still 6-飞越主世界俯冲边城 2017 --to-preview 工作-遮罩

# 分级冻结在这一帧，镜头挪到城正上方 4.5 km 往下看
REMOTION_ANIM_TRIAL='{"按级着色":0.5,"调试镜头":{"位":[9200,4500,-5000],"看":[9200,60,-5001]}}' anim still 6-飞越主世界俯冲边城 2017 --to-preview 工作-俯看分级
```

## 分级色调

`{"分级色调": {…}}`，键的落点见 `engine/voxel/分级色调.ts` 文件头。

| 键 | 值 | 做什么 |
|---|---|---|
| `定级` | 级（0～6） | `定级框` 里的区段一律用这一级，框外照门槛。用户 11-17 定：不整帧强制最细一级，几何只多要量的那一小块 |
| `定级框` | `[[[x, z], [x, z]], …]` | 每个框两个对角（游戏坐标，`场景: true` 按场景坐标）。不给就用各个 `区域` 的外接框，两样都没有不定级 |
| `真几何` | `true` | 配 `--tele`：挑区段、定级别按望远后的视锥和像素算（默认照原整帧）。高倍时那片地落在细级上，再配 `--truth` 就是「该是什么颜色」 |
| `阴影` | `false` | 地形不投影 |
| `AO` | `"关"` / `"满"` | 屏幕 AO 不压地形 / 不按距离减弱 |
| `并色` | `false` | 台阶并色全关 |

## 量平均色

区域遮罩和正常画面用同一个试看参数（只多一个 `区域遮罩`）各出一张，按遮罩里区域色的像素在正常画面上取平均（线性 RGB）。边上被抗锯齿混了的像素不是区域色，自动不算。换门槛、换帧、挪镜头、望远，量的都是同一块地。

比同一块地在各级的颜色：`区域` 圈住那块地，`分级色调.定级` 依次给 0、1、2，每级出正常画面、`区域遮罩`、`材质遮罩` 三张（`anim still --trial` 一次出几组），用 `--tele` 原生渲。

## 量切级那一帧跳了多少

切级的跳变和镜头运动混在一起量不出来：镜头在动的片子里相邻两帧本来就有两到五成的像素差超过 8 级。把画面镜头定在某一帧的位姿（`调试镜头`，位姿从 `切级日志` 或 `[地形调试] 镜头` 那行抄），挑区段还照段里每帧的镜头走，连出前后几帧：画面上只剩「这一帧换了什么」，再拿 `anim diff` 比相邻两帧。

```sh
C='"调试镜头":{"位":[10606.9,524.2,-5952.0],"看":[10528.2,487.9,-5902.2]}'
V='"加载视点":{"位":[10606.9,524.2,-5952.0]}'
anim still 6-飞越主世界俯冲边城 1949 1950 1951 1952 --to-preview 工作-切级-分因 \
  --trial "{$C}" --trial "{$C,\"分级色调\":{\"阴影\":false}}" --trial "{$C,$V}"
```

- 第 1 组是现状；第 2 组关投影，剩下的只是地形切级；第 3 组用 `加载视点` 把分级冻住，剩下的只是影子在变。两种跳变分开量，别都算在切级头上
- 人物、太阳照样在动，整帧比的时候会算进去：望远对着地面量，或者把第 2、3 组里都变的像素去掉再数

## 切级跳变调查（11-17，留档 `实验/切级跳变`）

段 `6-飞越主世界俯冲边城` 第 1900～2079 帧，用户看到切级那几帧「形状跳变，突然多了一个坑」「色差仍然明显」「突然多一堆白点」。原因查清了，试的四个修法都没进主线，留在标签 `实验/切级跳变`（`767f9eb3`）。下面的数都是在标签上量的；这几帧的交界距离、换级的区段、影子切分在主线上用 `切级日志`、`阴影日志` 核对过，一样。对比图、视频和完整的数在主检出 `预览/1117-1055-地形切级跳变/`，上一轮（各级色调）在 `预览/1117-0655-地形各级色调/`。

**为什么没采用**：用户 11-17 看片后定，飞行镜头改用航线定级（按航线往后看 5 秒提前定级、留细、下限 1.125、门槛 4.5），效果比下面的 过渡带 + 阴影切分平滑 好，也快很多（「修复切级跳变的那个方案好像用不上了，那个备案做技术沉淀吧」）。

### 原因

那几帧的跳变有两个互不相干的来源：

- **地形切级**：区段离镜头近过界就整块换细一级。游戏坐标 x 9216～9472、z −6144～−5632 的两块 256 米区段在第 1951 帧从 2 级换成 1 级，离镜头 1120～1380 米，1、2 级的界是 1213 米。粗一级的格子取格里最高的方块（Voxy 的合并规则），坑底被填平、台阶线少而粗，换细那一帧坑和细台阶线一起冒出来。
- **影子跳档**（和地形分级无关，分级冻住照样跳）：级联阴影的切分取 2 × 镜头离地，再按四分之一个八度取整。离地按航线下面 64 米一格的地面算，镜头一帧飞 16 米，离地一帧一变。第 1949～1952 帧没取整的切分是 723、736、712、726 米，取整后中级到 724、861、724、861 米。中级一像素约 1 米、远级 4 米，离镜头 650～860 米那一圈地的影子一帧用中级、一帧用远级，坡上台阶的影子整片出现又消失。

镜头定住量相邻两帧（上一节的量法，去掉人物、太阳），整帧 3840×2160，每格是「16×16 超门槛块数 / 差超过 8 级的像素占比」：

| 相邻帧 | 现状 | 只看切级 | 只看影子 | 过渡带 + 阴影切分平滑 |
|---|---|---|---|---|
| 1949→1950 | 59 / 2.16% | 0 / 0.02% | 59 / 2.15% | 4 / 0.14% |
| 1950→1951 | 96 / 2.51% | 27 / 0.35% | 60 / 2.13% | 6 / 0.14% |
| 1951→1952 | 113 / 2.49% | 38 / 0.29% | 58 / 2.15% | 3 / 0.13% |
| 1952→1953 | 79 / 0.43% | 77 / 0.40% | 0 / 0% | 19 / 1.37% |

最后一行修后的 19 块是阴影真换档的那一帧（见下面「没解决的」）。

### 试过的修法

| 试看名（在标签上） | 做法 | 效果 | 代价和没解决的 |
|---|---|---|---|
| `过渡带` | 每级交界前留一条带（离镜头 界 × 0.75 到 界），细分掉的粗一级节点叠在细一级上，逐像素按离镜头的距离渐变着混；画面上每一点显示哪一级只看距离，不看区段边界 | 只看切级，第 1950→1953 帧三对相邻帧差像素合计 1.037% → 0.025%，16×16 超门槛块 27、38、77 → 0 | 带里能看见半透明的粗方块，带里比现状略粗；粗一级的影子在界上是一条线换过去；水、花草不叠；只在屏幕 AO 走三遍离屏时生效 |
| `阴影切分平滑` | 切分换成前后各 0.5 秒的加权平均，着色里中、远两级的交界跟没取整的切分走，级联大小照旧按档 | 只看影子，每对 58～60 块、2.1% → 不换档的帧 1 块以内、0.1% | 真换档的那一帧还要闪一次；只接了 6-2-5 飞越主世界 |
| `分级色调.树叶按占比` | 粗级树叶照合并规则「有一片就占整格」，树冠每粗一级胀一圈。运行时从第 0 级重算 1～3 级，树叶按竖直、东西、南北三个方向平均挡住几成，就按几成有序抖动着留 | 块A 树叶占比 0 级 84%、1 级 97%、2 级 99.6% → 1、2 级都约 93% | 运行时重算每帧 0.43 → 1.03 秒，要用得做进烘焙（`pipeline/世界/烘焙/合并.ts`）；只管 1～3 级；结果随视角变 |
| `分级色调.树叶洞` | 粗级实心树叶贴图透明处的填色系数（主线 0.6）可调 | 配 `树叶按占比` 取 0.85，块A 整块 ΔE 1 级 3.22 → 1.02、2 级 5.18 → 1.98 | 单改会让 2 级更亮；0.85 只在一个机位量过；0.6 是用户看过的现状 |

按原因分（只看切级，三对相邻帧差像素占整帧的比例）：

| 原因 | 现状 | 过渡带 |
|---|---|---|
| 地面变地面（地形高度、台阶、坑） | 0.539% | 0.007% |
| 树叶和地面互换（树冠大小） | 0.088% | 0.000% |
| 树叶变树叶（叶子明暗、树冠形状） | 0.266% | 0.006% |
| 带近白像素的（白桦原木） | 0.044% | 0.003% |
| 别的（水、花草、城） | 0.100% | 0.008% |

`过渡带` + `阴影切分平滑` 一起开，3 秒试看片 74 → 85 秒（约多 15%），不用重烘。`树叶按占比` 进烘焙的话主世界-116 重烘估 13～15 分钟、包 215～225 MB，这两个数是估的，没实测。

### 各级静态色差

同一块林地（块A，游戏坐标 9400,−5000 到 9528,−4872）定成 0、1、2 级，第 1999 帧从 850 米外、俯角 21° 看：

| 版本 | 树叶占这块地 | 树叶亮度比 0 级 | 整块 ΔE |
|---|---|---|---|
| 0 级 | 84.3% | 0 | 0 |
| 1 级 主线 | 97.2% | −6% | 3.22 |
| 2 级 主线 | 99.6% | +10% | 5.18 |
| 1 级 `树叶按占比` | 93.6% | −12% | 3.75 |
| 2 级 `树叶按占比` | 93.2% | −4% | 3.51 |
| 1 级 `树叶按占比` + `树叶洞` 0.85 | 93.6% | −1% | 1.02 |
| 2 级 `树叶按占比` + `树叶洞` 0.85 | 93.2% | +7% | 1.98 |

- 1 级树叶偏暗不是 AO 也不是投影：关 AO 后仍比 0 级暗 9%，关投影后暗 12%
- 1、2 级用同一张实心树叶贴图，两级的差来自形状：2 级树冠几乎盖满，是一整片受光的顶面，1 级还有侧面
- 树冠大小和贴图填色系数要一起改才对得上
- 和视角有关：上一轮另一个机位 `树叶按占比` 单开 2 级 ΔE 1.53，这里 3.51

白点是白桦原木。粗级的合并规则里原木赢空气，树干在 1 级宽 2 米、2 级宽 4 米；主线上被胀大的树冠挡着（块A 近白像素 0 级 6652、1 级 329、2 级 0），树冠收小以后露出来（`树叶按占比` 下 1 级 3325、2 级 1028）。

### 俯角

交界处的俯角（镜头看交界那块地，水平是 0°），每 60 帧取一帧，用 `切级日志` 量：

| 交界 | 主世界段：中位（一成～九成） | 暮色 `6-穿塔斩首领`：中位（一成～九成） |
|---|---|---|
| 0、1 级 | 10.4°（5°～85°） | 4.5°（0.1°～8.2°） |
| 1、2 级 | 4.9°（2.6°～29°） | 2.9°（0.4°～4.3°） |
| 2、3 级 | 2.8°（0°～19°） | 1.2°（0.4°～2.2°） |
| 3、4 级 | 1.2°（0.5°～6.5°） | 0.8°（0.1°～1.1°） |
| 镜头离地 | 158 米（81～1314） | 62 米（−17～148） |

绝大多数帧是 1°～10° 贴着地看过去，不是从正上方看：粗格「取最高」把树冠、台阶抬高一格，看到的主要是侧面和轮廓。一个固定角度也不够，主世界同一段里 0、1 级交界从 5° 到 85° 都有。给粗级定合并规则、定颜色时按这个分布，不按竖直方向。

### 什么时候值得捡回来

- **影子来回跳档**：和地形怎么定级无关，航线定级不管它。主线上第 1949～1952 帧影子照旧来回跳（上表「只看影子」一列）。`阴影切分平滑` 不靠 `过渡带`，可以单独捡。切分都是 `max(300, 2 × 离地)`（`作品/应力转动/地点/飞行镜头.tsx`、`engine/light/暮色光照.tsx`、`engine/light/画法/主世界.tsx`、`暮色.tsx`），取整在 `级联阴影.ts` 里：别的镜头有没有来回跳没查，用 `阴影日志` 看
- **阴影真换档那一帧的闪**：按档取整本来就有，全片每次换档都有。能做的是中级的像素大小只在整八度处变，换档次数少到四分之一，近处影子最多糊 1.7 倍
- **没登记航线的镜头**（地面段、摇镜头、跟拍）：切级照旧整块换，`过渡带` 不靠航线
- **各级静态色差**：换级挪到远处以后不跳了，但各级颜色还是不一样。要做就是 `树叶按占比` 进烘焙，同时调填色系数，先在两三个机位上量再定数（按上面的俯角分布挑机位）
- **粗级树干变粗**：烘焙的合并规则，原木也可以按占比
- 标签上各修法的做法写在 `engine/voxel/过渡带.ts`、`engine/voxel/树叶按占比.ts` 的文件头和 `engine/light/级联阴影.ts`（`smoothedSplit`、`shadeAtSplit`）；那里的 `docs/地形调试.md` 有两个试看的用法
