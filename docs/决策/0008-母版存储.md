# 0008 母版存储：存 CRF12、渲完删旧

- 状态：代码已做（10-31）。主数据根上的一次性转存和真删，合并后照下面「现有数据怎么迁」做。
- 依据：用户 10-30 的话（下面照录）。设计和实测：`预览/1030-1755-母版管线重设计/01-推荐方案.md`（段签、认可参考、交付自足、解钉顺序）、`09-补充-能不能用压缩版.md`、`02-实测数据.md`。不做的：01 第五节的预算和 LRU、`[存储]` 配置，第六节的冷盘。

## 落在哪

| 什么 | 在哪 |
|---|---|
| 存法 | Remotion 照旧渲 CRF1（`渲染参数` 的 `crf: 1` 进指纹，指纹不变）。渲完在渲染闸里先派生段签，再转 x264 CRF12（`-preset veryfast -crf 12 -threads 4 -pix_fmt yuv420p`，声音 PCM 原样拷），删 CRF1。`pipeline/渲/转码.ts`、`转存.ts` |
| 文件名 | `cache/母版/<作品>/<段键>/<指纹前 16 位>.mkv` 是 CRF1，`.crf12.mkv` 是 CRF12（文件里另写 `ANIM_STORAGE` 标签）；分开起名，转码中断 CRF1 还在，共用数据根的旧检出也不会把 CRF12 当 CRF1 去比像素 |
| 记录 | 段签 `签.json` 的 `母版`：现在这份的字节 sha、大小、改于，`转码自`（CRF1 那份的样子），`存法`（标签、参数、ffmpeg 和 x264 版本）；`manifest.json` 每段记 `存法` |
| 谁读 CRF12 | `film`、`edit-package`（缺画面现做时）、`render --到预览`：`转存.ts` 的 `备好母版`，只有 CRF1 的旧母版先照同样参数转码再用。叠层 ProRes 4444 不转 |
| 自动删旧 | `render` 写好某段某级别的新指纹后，删同段同级别别的指纹的媒体文件（`.指纹.json` 留着）。跳过：还没自足的交付引用的、还没有认可参考的认可那版（只留 CRF1）、这个指纹正在写（`.渲染中`、`.转码中`）、近 2 小时被 render、film、verify、edit-package 用过的（旁边的 `.用过`，各文件各记各的，不设共享账本）、级别读不出的。`pipeline/缓存/钉.ts` |
| gc | `anim cache gc` 同一套钉：当前指纹不删；同一指纹的 CRF1 转存后已被取代（段签记着转自它、CRF12 在），除非认可、待补画面的交付还要它；过期的（重渲取代的、自足后没人引用的）可删；每段每级别最近一份、近 2 天渲的照留；默认只打印，`--执行` 过渲染闸 |
| 没有上限 | 不设预算，不按 LRU 删当前指纹 |

## 声音放哪

CRF12 的 mkv 里原样留一份 PCM，不只放 FLAC。理由：CRF12 自己能放能用，段签丢了 film 还能出片；每分钟约 11 MB，只占 CRF12 的 1～2%。

## 为什么不用重渲

转码不是渲染：从现有 CRF1 转出来，同一份输入、同版本 x264、固定 4 线程逐位相同，两部作品当前指纹 62 个实测 251 秒转完。指纹不变（`crf: 1` 表示「怎么渲的」，还是真的）。

## 为什么 verify 不受影响

verify 永远不拿 CRF12 的像素按 1e-3 门槛比（地形差 > 16 占 2.4e-2，比就全不过）。新这一版只用渲完时从 CRF1 抽的无损抽样帧（段签 `抽样.mkv`），认可那版用认可参考（`认可参考/`），门槛一字不改。段签只从 CRF1 派生，`出段签` 拒收 CRF12。抽样帧丢了、CRF1 也没了，报「要重渲才能验收」，不静默退回。

`verify --对基线` 要逐帧比，落点帧不全在抽样帧里，只有 CRF1 能比；只剩 CRF12 的同样报要重渲。

## 现有数据怎么迁

一次性，顺序不能换（前面的都是后面删得掉的前提，要 CRF1 还在）：

1. `anim render --只派生`（两部作品）：回填段签。
2. `anim verify 补参考`（两部作品）：认可有了参考才解钉。
3. `anim film 补声音 --全部`（两部作品）：交付自足才解钉。补画面要出片时那份 CRF1，所以在转存之前。
4. `anim cache 转存`：只打印要转什么、转完 gc 能删什么；加 `--执行` 转，不删 CRF1。
5. `anim verify`（两部作品）：结论和转存前一样。
6. `anim cache gc --只 母版,叠层` 看过再加 `--执行`。

没开剪辑包的作品（把回忆拼好给你）film 不出画面，交付一直不自足，旧交付引用的母版一直钉着。要腾这部分得删旧交付，由用户定。

## 没做的

- 不同机器、不同 ffmpeg 版本转出来的字节不一样（同版本才逐位相同）。段签记了版本；出片对得上指纹就行，不要求跨机器字节相同。
