# 0002 资产标准

- 状态：已定（用户 10-21），具体许可逐条在 M2 资产入库时登记
- 用户 10-21：公用资产以后都会用到，全部按新标准整理、便于开源；不只公开的资产，自己常用的（李樱、九胡的建模等）也要整理。

## 范围

- **全部纳入资产表**：`设定/` 图库、模型、贴图、声音、网格、地形包、取材 mod 和 mcai 的产物。
- **重点是自己做、以后常用的资产**：按「角色包」整理成拿来就能复用的一套（见下）。
- **仍留在旧项目的**：第 4、5 章漫画旧稿、番外正文、image-flow 出图流程（候选图在 `~/.image-flow/`）。
- 旧项目里的原件不动，字节用 `cp -c` 克隆进 `store/` 或 `私有/`。已删段的素材（护盾术 wav、风矢思索）不导入。
- 备选版本（6-斩娜迦 旧动作、6-挡箭 备选时钟等）不留活代码，渲成对照 mp4 放进数据根 `archive/`。

## 每条资产的字段

`assets/registry/*.toml` 由人写，`assets/资产锁.json` 由 `anim assets import` 生成，不手改。

| 字段 | 说明 |
|---|---|
| `id` | `<类>/<名>`，代码里只写它，如 `模型/角色/李樱`、`贴图/实体/九胡`、`音效/entity.warden.roar`、`配音/7-刘心忠-不可能` |
| `sha256`、`大小` | 资产锁里由工具填 |
| `类别` | 模型、贴图、网格、碎块、音效、配音、音色、配乐、设定图、截图、地形、mod 产物等 |
| `来源` | 三选一：`提取:<配方>@<jar sha>`（照 `sourcing/extract.toml` 从 jar 取）、`手工:<说明>`（自己做的或别人给的）、`派生:<输入 sha>+<参数>`（由别的资产算出来，如配音成品 = 原件裁静音再拉到 −18 LUFS） |
| `许可` | SPDX 表达式，如 `MIT`、`CC-BY-NC-SA-4.0`；不在 SPDX 列表里的写 `LicenseRef-<名>`，如来源不明的 `LicenseRef-Origin-Unverified` |
| `可见性` | 四选一，见下 |

可见性：

| 值 | 含义 | 字节放哪 |
|---|---|---|
| `公开` | 可以放进公开仓库 | `store/` |
| `发布` | 可以公开分发，但体积大，挂 GitHub Release 附件、不进 Git 历史（场景网格、地形包分卷） | `store/`、`terrain/` |
| `提取` | 不分发字节，只公开配方，使用者在本机从自己的 jar 提取（模组贴图、模型、声音；夜幕刀光、殖民地蓝图） | `store/` |
| `私有` | 不公开 | `私有/` |

- `anim check` 查：引用到的 id 都已登记，许可、来源、可见性齐全；公开构建的依赖闭包里不能有私有资产。`--深` 时逐个核对 sha。
- 许可直接沿用旧项目的 `参考模型库/工具/开源/公开版.toml` 和 `工具/取材/模组清单.json`，不重新判断；那里没写的，标「待定」列给用户。

## 角色包

自己常用的角色按角色整理成一包，登记在 `assets/registry/角色/<角色名>.toml`，换项目、开源都能整包拿走：

| 内容 | 例（李樱） | 例（九胡） |
|---|---|---|
| 模型 | `模型/角色/李樱`（旧 `参考模型库/src/模型/角色/李樱.体素.json`） | `模型/角色/九胡`、`贴图/角色/九胡`（旧 `九胡.模型.json/.png`） |
| 生成源（进 Git） | `assets/src/角色/李樱/build_li_ying.py`，模型由它导出，不手改 | 无（模型取自模组） |
| 设定图 | `设定图/角色/李樱/三视图` 等（旧 `设定/角色/李樱/`） | `设定图/角色/九胡/三视图` 等 |
| 声音 | `音色/李樱/参考音频` | `音色/九胡/参考音频` |
| 说明 | 外观基准、比例、量测方法、用户纠正过的点 | 同左 |

每个文件照上面的字段各登记一条；包里的说明写清哪张图是基准（李樱的 3D 模型以 `李樱三视图.png` 为准）。

## 已知的许可和可见性（逐条登记时照这个，用户 10-20、10-21 定）

- 自己写的代码用什么开源协议：用户 10-25 说「这个开源协议暂时不写 后面再决定」，不加 LICENSE；第三方资产按各自协议；接受 CC BY-NC-SA 资源带来的不能商用。
- 九胡模型取自 YSM「大正女仆酒狐」，CC BY-NC-SA 4.0。
- 九胡的配音和音色参考来自第三方语音包，**私有**；李樱、刘心忠、黄叛的 AI 参考音频可以公开；文件名带「录音」的用户本人录音一律**私有**。
- 小说原文**私有**（原作者授权给用户本人）；原作者授权在公开仓库里再分发改编内容。
- 重锤资源包来源不明，照放，许可标 `LicenseRef-Origin-Unverified`，作者找来就撤。
- 场景网格几何、地形包可以发，可见性 `发布`；地形包不进仓库（用户 10-25：太大，放 Release）。把回忆拼好给你 渲片用到的 `提取`、`发布` 字节随仓库发，见 `0005-随仓库发字节.md`；应力转动 的挂 Release `assets-v1` 发，见 `0006-挂Release发字节.md`。
- Terralith、Continents 禁止 AI 用途，不用。
- **待用户定**：image-flow 生成的设定图（三视图、立绘）能不能公开。定之前按 `私有` 登记。

## 不可再生的东西

配音原件和成品、用户录音、旧场景网格、世界存档、片场存档。前四类进 `store/` 或 `私有/`，世界存档和片场存档留在 game 环境里，都要做离机冷备份。配音不重出（TTS 有随机性，又经过人工挑选）。
