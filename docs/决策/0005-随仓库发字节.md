## 落在哪

| 什么 | 在哪 |
|---|---|
| 随仓库发的字节 | `<作品根>/字节/<sha 前两位>/<sha256>`，布局同数据根 `store/`；`.gitattributes` 标 binary（换行被改了 sha 就对不上） |
| 发哪些段 | `<作品根>/随仓库.toml` 的 `"段" = ["<段键或章>", …]`；把回忆拼好给你写的是 `["2", "核对-封面帧"]` |
| 集合怎么算 | `pipeline/资产/随仓库.ts` 的 `算随仓库`：只算 随仓库.toml 列的段（用户点名的范围，不扩大）：这些段的 画面、段.ts、`engine/段/设置.ts`、作品 `index.ts`、叠层入口沿依赖图走到的 `asset:`，加 cue 的资产、台词的配音，加 `anim film` 自己读的（音效起音；有台词时字幕卡的像素字）；私有的不带 |
| 重新生成 | `anim assets vendor [--检查]`：从数据根 store 拷、逐件核 sha，删多余的；`--检查` 只报要改什么 |
| 核对 | `anim check` 的 资产：字节/ 和现算的集合一一对上、逐件核 sha、私有的不在里面；没写 随仓库.toml 的作品不该有 字节/ |
| 补进数据根 | `anim render`、`still`、`film`、`studio` 开头自动补，也可以 `anim assets seed`：字节/ 里 store 还没有的核过 sha 补进去（APFS 克隆，别的文件系统退成普通复制），已有的不动 |
| 别的段缺字节打包不失败 | Remotion 一次把整部作品的 `段/`、`核对/` 都打进一个包，别的段 import 的字节（私有的，或九胡、李樱这类没随仓库发的）公开仓库没有。`pipeline/资产/缺字节.ts`：闭包碰到缺字节资产的段入口（画面.tsx、叠层*.tsx）整个换成一渲就抛错的组件（只换 `asset:` 不够：`库/角色/九胡.tsx` 这类在模块顶层就取字节，注册时一抛整个包都读不出 Composition）；别处的 `asset:<id>` 换成一取值就抛错的模块。报错说清缺哪件，不悄悄换图；数据根字节都在时什么都不做。接在 `webpack改写` 外面（`渲/渲.ts` 的打包、`remotion.config.ts`），不动 `webpack.ts`（它的文本进所有段指纹）。闭包里有缺字节资产的段，指纹多一项 `缺字节`，补上字节就过期 |
| 歌缺了换静音 | 渲染代码按 id 现取（`engine/audio/私有配乐.ts`），不打进包；打包前 `pipeline/资产/私有配乐.ts` 在 `<数据根>/cache/私有配乐/<id>` 备好：`私有/` 里有就拷那份，没有就写一份盖住所有 cue 的静音 wav（多留 1 秒），public 目录多一个链接 `私有配乐`。段指纹多一项 `私有配乐`（sha 或「缺:静音」），补上歌以后用到它的段过期、重渲就带歌 |
| 说明 | 仓库根 `README.md` |

- 可见性：`提取`、`发布` 在 `0002` 和 `assets/README.md` 里原本是「公开版不带」；写了 随仓库.toml 的作品，渲片用到的照样随仓库发（就是这条决定）。别的作品不变。
- 带歌渲出来和改之前一样：10-25 在 worktree 里带歌重渲第 2 章、`anim film 2`，和 `交付/把回忆拼好给你/1025-0248-成片/成片.mp4` 逐帧、逐样本比过。
- 现在：`["2", "核对-封面帧"]` 共 20 段，字节/ 239 份（248 个 id，几个 id 同一份字节只放一份），约 8.8 MB；私有不带 1 件（歌，换静音）。公开仓库打包时换占位的 5 个入口：`段/1-一如既往`、`核对/第一人称`（李樱体素），`核对/魔法酒狐表情`（九胡模型、贴图），`核对/三渲二`（九胡、像素字、私有截图），`核对/隐世之境一楼`（私有截图）。九胡（kit 写「3D 模型只能从 jar 提取，不进公开仓库」）、李樱（应力转动的）不在用户点名的范围里，不随仓库发。
- Mac 冒烟（10-25）：在 scratchpad 里 clone 这个分支、数据根指向空目录，`anim assets seed` 补进 239 份、再跑补 0 份，改坏一份报 sha 对不上；`anim check` 通过；`still 选择世界 30` 和主数据根渲的逐字节相同；渲换了占位的 `核对-魔法酒狐表情` 报「…要的字节「模型/角色/九胡」「贴图/角色/九胡」不在数据根…这段渲不了」。

## 没做的

- 地形包放 GitHub Release（tag 拟用 `assets-v1`，见 `docs/待办.md`「开源」）：把回忆拼好给你 不用地形包，这次不发。
- 应力转动：配音（九胡的第三方语音包）、配乐、取材账号皮肤这些私有素材缺了怎么降级没定完，地形包要等 Release。
- 歌的 sha 是抽出来那份 m4a 的文件 sha；别人用别的 ffmpeg 版本 `-c copy` 抽，容器里的编码器字段可能不同，sha 就对不上。要不要改成认解码后的 PCM，等 Windows 验收时再看。
