## 落在哪

| 什么 | 怎么做 |
|---|---|
| 可见性 | 资产表里所有 `私有` 都改成 `发布`：共用 436 件、亚波伦不放水 43 件、把回忆拼好给你 2 件。取材配方 `sourcing/extract.toml` 里 3 条私有产物也跟着改。说明里写着「不公开」「不能分发」的，前面加了一句这次的决定 |
| 字节放哪 | 留在数据根 `私有/` 库，资产锁的 `库` 不改。改了的话，按 cue 现取的配乐（`是私有配乐`，看的是 `库`）会改走打包，`声音地址.生成.ts` 跟着变，把回忆拼好给你、亚波伦不放水几乎每段的指纹都会变。现在 `私有/` 只表示字节放在哪，能不能发看可见性 |
| 检查 | `anim check` 只要求可见性是私有的在 `私有/` 库，反过来不查（`pipeline/检查/规则/资产.ts`） |
| 发什么 | `随发布.toml` 的 `段` 写 `["全部"]`，表示清单里的每一段，以后加章不用改表；三部作品都写。集合还是 `算随仓库`。可见性私有的不发；`私有/` 库里可见性不是私有的记进 `私有库件`。算集合时先套 `换用.toml`：亚波伦不放水 的附加方块表以前没算进去 |
| 附件 | 同一个字节 tar 里，`私有/` 库的字节放在 `私有/<sha 前两位>/<sha>`，发布锁记在 `私有库字节`。附件名把这批也算进去；没有这批时和以前同名，旧锁照用 |
| 下载 | `anim assets pull` 把 `私有库字节` 放回数据根 `私有/`，`store/` 的照旧 |
| 随仓库 | 把回忆拼好给你 的 `字节/`（第 2 章，进 Git）不变，还是只放 `store/` 的。歌要从 Release 拉 |
| 文档 | `README.md` 改成写给人看的：放可复制的 prompt，引用 `docs/从零渲染.md`（Windows 起，一步一步，按 DeepSeek-V4.1 Flash 能照做来写）和 `docs/二次开发.md` |
| doctor | 各作品按发布锁报一项 `素材·<作品>`；共用资产锁里没段用到的（参考图、旧版，Release 不发）缺了、数据根子目录还没建，有发布锁时只提示，不算必需项没过 |
| Windows 画面 | `ANIM_GL` 在 Windows 上默认 `vulkan`（11-02 实测 D3D11 同帧两遍 45/86 帧不同，Vulkan 0/86），不让人自己去配 |

## 下载源（11-13）

| 下什么 | 从哪下 | 怎么落的 |
|---|---|---|
| Git、Node 24、ffmpeg | npmmirror 的 binary 镜像（git-for-windows、node、ffmpeg-static） | `docs/从零渲染.md` 第 2 步给 `curl.exe` 地址。ffmpeg-static 是 gyan.dev 的 6.1.1 essentials，不带 libsvtav1，只影响 `film --分享版` |
| pnpm、npm 依赖 | `registry.npmmirror.com` | 第 2 步 `npm config set registry`，pnpm 也读它；锁文件不记仓库地址，不用改 |
| 渲染用的浏览器 | Remotion 要从 storage.googleapis.com 下 Google 那份时，改从 npmmirror 的 chrome-for-testing 镜像下（`ANIM_CHROME_MIRROR`），核 sha256，下不成再交给 Remotion | `pipeline/渲/浏览器.ts`。win64、linux64、mac-x64 三个包的 MD5 和 Google 一致。Apple 芯片 Mac、glibc 2.35 起的 Linux 用 Remotion 自己打补丁的构建（remotion.media），镜像上没有，照旧 |
| 代码、`gelatin-game-engine`（codeload.github.com）、Release 附件 | 只有 GitHub | 文档写明「国外，最好走代理」。`assets pull` 的前缀可以换成加速站（`ANIM_GITHUB_MIRROR`），附件都核 sha256；下 5 次都失败时提示走代理 |
