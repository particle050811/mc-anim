# 0016 法术录制：在取材客户端里放一遍，逐刻录粒子、实体、声音，画面里按两点摆回去

- 状态：原型（11-10）。取材 mod 的 `record`、`hold` 动作，`sourcing/extract/录法术.py`，配方 `sourcing/extract.录制.toml`，回放 `作品/亚波伦不放水/法术/演出/零件/录制回放.tsx`，核对段 `核对-法术录制`。录了 2 个法术（frost_nova、weakening），还没有正片用。
- 依据：用户 11-10「可以弄录制路线，我看那个 Blender 插件也是录制路线」。这是 `docs/待办.md`「模组特效导入接口」的第 3 步；10-30 说的「`mcai record` 用不到」由这句取代。
- 和别的路线：贴图、声音、粒子定义 json 照旧按配方从 jar 导（第 1 步）；粒子类的常数用字节码翻译（第 2 步，0007 的符号执行）；法术本身是服务端 Java 逻辑，翻不出来，用录制。已经手写的 71 个法术不重做；录制是新法术的另一条路，也给手写版当对照。

## 录什么（`mcai record`，`sourcing/mod/src/main/java/mcai/record/Recorder.java`）

- 时钟：客户端刻。每刻末尾（ClientTickEvent END）拍一次快照；包在 tick 前处理、新粒子在引擎 tick 末尾才进列表，所以出生那刻的快照就是刚构造完的状态。游戏画的位置 = lerp(上一刻快照, 这一刻快照, 分刻)，和 `interpPathPos` 同一条「晚一刻」的规矩。
- 粒子（ParticleEngine.createParticle/add 的 mixin）：类型 id、`ParticleOptions.writeToString`、类名、渲染类型、出生刻、死亡刻、构造参数；构造完的字段（位置、速度、寿命、重力、摩擦、碰撞、颜色、转角、碰撞盒、quadSize）；每刻一行 `[x, y, z, getQuadSize(0), r, g, b, a, roll, 贴图格]`，贴图格按 `sprite.contents().name()` 记名字。
- 改写了 `render(VertexConsumer, Camera, float)` 的粒子：每刻替它画一遍（分刻 0），顶点接到一个不往显卡送的 VertexConsumer。正好 4 个顶点的照普通方片记，大小、颜色、透明度改用画出来的值（SpellSquareParticle 只在 render 里改透明度再调父类）。别的整份记顶点（世界坐标、贴图格内 uv、颜色）。冲击波环就是这样录下来的。
- 实体（`entitiesForRendering`，不含玩家）：半径内的出没、类型、uuid、类、碰撞盒，每刻 `[x, y, z, yRot, xRot, 头, 身]`，NBT 在服务端线程取一次。
- 声音：客户端 PlaySoundEvent 记刻、事件、位置、音量、音高；声音线程的 PlaySoundSourceEvent 补实际变体文件。只录得到客户端听见的。
- 诡厄 Start/Cast/StopMagicEvent（反射订阅，mod 不编译依赖诡厄）：记刻、法术类、是否服务端，用来定「出手」。
- 施法：`use=1` 在第 `pre` 刻走游戏自己的 startUseItem（同真人点右键），蓄力、引导的按住到 `hold` 刻或不再使用。`seed` 定服务端世界和玩家的随机数。

## 格式（`mcai-录制/1`，录法术.py 整理）

- 一件资产一个 json：`录制/法术/<模组>/<法术>`，作品资产表 `录制.toml`（类别 录制）。一行一个粒子、一个实体，好 diff。
- 坐标：场景局部坐标（Z 朝上）。原点 = 施法者脚底，前 = 施法者到目标的水平方向，右 = 前 × 上，上 = 竖直，单位格；角度是相对前方向的 yaw。刻从「出手」算：服务端 CastMagicEvent 之后第一个粒子或声音那刻，出手前的蓄力粒子是负的。
- 主要键：`法术`、`法杖`、`聚晶`、`距离`、`种子`、`刻数`、`施法者 {眼高, 目标, 轨}`、`贴图名`、`贴图资产`（名字按 `minecraft:x → 贴图/特效/粒子/x`、`ns:x → 贴图/法术/ns/particle/x` 换成资产 id）、`摘要`（按类型数、自画网格、实体、声音、半径外没记的、没登记的贴图）、`粒子`、`实体`、`声音`、`事件`、`轨列`（各轨每列的含义）。
- 粒子：`类型 类 画法 自画网格 生 寿命 半边长 重力 摩擦 碰撞 色 位 速 参数 轨 [网格轨]`。

## 回放（`录制回放.tsx`）

- 输入：录制、出手后的秒、施法者脚底、目标、贴图表（贴图名 → Png）。按脚底和目标两点把局部坐标摆回场景。
- 方片：位置、转角取上一刻到这一刻的插值，大小取这一刻到下一刻（getQuadSize 带分刻），颜色、透明度、贴图格取这一刻；画法 OPAQUE → 镂空、TRANSLUCENT → 半透明；同一张贴图一批，用 `面片们`。
- `动法 = '算'`：位置改由出生字段（位、速、重力、摩擦、碰撞）按 `@库/特效/粒子面片.tsx` 的 `particlePath` 重算。类改写了 move、不碰撞的（FlameParticle），录下的轨迹会钻到脚底以下，这种就当不碰撞。
- 网格轨：照录下的顶点画（前后两刻插值）。实体除了目标只画线框占位盒。声音不在组件里放，段照 `声音` 表放。

## 核对（预览 `1110-1704-法术录制对比`）

- `核对-法术录制`：一帧三格同机位同时刻：手写演出、录制·轨、录制·算。全景照 `核对-法术演出`，近景对着施法者。
- frost_nova、weakening 都很像：冰晶球的大小、扩散速度、贴图、冲击波环，紫方块的分布、上飘、淡出都对得上；轨和算几乎重合（出生字段加原版物理就能复现轨迹）。不同的只有随机的那部分（每颗的位置、大小），以及 weakening 的环录制版略亮一点（没查）。录到的声音（ice_chunk_hit 音量 1 音高 0.5、weaken_cast 音量 2）和手写元数据一样。

## 限制

- 一份录制是一次随机结果。粒子自己的随机数没有种子入口（客户端 Particle 各自 new 的随机源），重录字节会变：锁对不上时删锁重登记。所以公开版不让使用者重录，录好的随公开版发（可见性 公开，配方 公开版 不提取）。
- 随地形、目标距离、目标是什么变的法术（命中、弹跳、地面裂缝），录的是录制那一刻的场地：平台 49×49 平滑石、目标 12 格外不动不出声的尸壳。距离不同时只是按两点拉伸方向，不会重算命中时刻。
- 自己画网格的录的是顶点，不是做法：换镜头看朝镜头的网格会不对（录制时镜头就是施法者的眼睛）；render 抛错的那刻没顶点。
- 半径（默认 32 格）外的粒子只计数不记。只录客户端听到的声音，服务端只发给别人的听不到。同一个法术刚放过有冷却，连录要等。
- 实体只画占位，模型、动画要另做（录到的 NBT、位姿可以喂给手写的实体）。

## 加一个法术

1. 取材客户端开着（过资源闸）：`MCAI_INSTANCE=取材客户端-诡厄 anim mcai game start world=法术录制`（存档用 `game copyworld name=法术录制 from=仪式对照` 拷的）。
2. `sourcing/extract.录制.toml` 照抄一条，改名称、法术注册名、产物 id；`anim --作品 亚波伦不放水 extract 录制-<法术> --登记`。
3. 没登记的贴图（摘要里列）先按粒子贴图配方导；画面里 `读录制(import 进来的 json)`，配上贴图表给 `录制回放`。
4. 用完 `anim mcai game stop`。
