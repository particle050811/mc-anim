# 0012：资源闸守底线，主 Agent 决定调度

日期：2026-11-01。状态：采用。

## 背景与归属

用户 10-04 定“控制一下并发，不要吃满内存”；10-05 定资源允许就多开，负载太大就一个一个来，综合 CPU 和内存；10-06 的“渲染并发降到 1”指标签页。30%、负载核×0.8、60 秒是 Agent 的实现，不是用户逐项定值。

用户 11-01 定的是总纲：不能只依靠写死的程序，主 Agent 要适时看整体资源、动态规划；监控成本高就适当时候看；日志应足够复盘，而不是反查会话。下面的决定（30% 下限、GPU 位容量 1、MC 客户端互斥、等内存不持锁、单票放行、压力 4 加 --强、不改像素、不做自动派发）是主 Agent 11-01 按总纲裁决的，不是用户逐项定值。

## 决定

1. 内存准入在拿锁前。单票人工放行可越过队序和内存，授权跟任务 id 走（票会改名），默认 30 分钟到期：轮到时当初看的读数可能已经过时；critical 压力 4 默认仍挡，需额外 `--强`。只动文件不开渲染的调用（`cache gc --执行`、`cache 改后缀`、清命中的旧）声明不开渲染，不判内存。
2. 队列 FIFO。主 Agent 用先、后、恢复、放行、让路、取消介入，必须写原因和快照。取消发信号前核对进程还是原来那个（票、锁判死的和启动晚于拿锁或领票的都不发：崩溃后 pid 可能被复用），决定事件记真实结果。暂缓/让路默认 30 分钟，到期回队尾；原位恢复需明确选项。没有隐式环境变量优先级（唯一的档是第 8 条显式的 `--低优先`）。
3. 普通多段段间重领票；正规批累计持锁 120 秒且有人等才交接，或显式让路。连贯必须说明原因；旧整批只能等或取消。
4. 月度追加调度日志，任务起止、票、锁、等待原因、身份、决定和告警可关联。同步信息文件提供在途帧数与心跳。SIGKILL 的崩溃由读者原子认领，非正常退出不再从耗时表消失。
5. 可注入的闸环境，测试隔离锁和日志。告警为纯函数，看守一次通知后退出。游标是月份加字节偏移；去重表只存进行中的事件，条件持续消失 5 分钟就结束，否则机器级告警一个数据根只醒得了 3 次。没有事件不输出，父死退出，有界等待单独退出码。
6. 调度快路径不加载 Remotion。渲染参数、同页路径、段序和指纹算法不动。
8. 低优先档（用户 11-06 定）：子 Agent 在 worktree 里只出静帧，整段渲染由主 Agent 合并后用 `anim --低优先 render …` 排。低优先的票名以 8 开头，排在全部普通票之后、暂缓票（9 开头）之前，彼此先来先渲；render 每段重领票，所以有静帧来时下一段就让它先走；低优先的正规批有普通票在等就在项间让，不等 120 秒；低优先票等得久不报「排队长」。`--低优先` 是全局参数，经 `ANIM_PRIORITY=low` 传给子进程。
7. 新旧长期共存：纯 pid 锁、原票名、主机旁文件、mtime 协议保留。`上次放行` 不能加第二行 pid：旧代码 `Number(全文)` 会得到 NaN；因此用旁文件扩展，旧读者继续守原间隔。无旁文件按旧语义处理。读路径见到旧票、旧锁记 `见到旧协议`，退役条件才看得见。

## 让路的依据和基线（11-06）

用 11-01～11-06 的 1564 张渲染锁票按到达时刻、持锁秒重放单锁队列（不含等内存，所以绝对值比日志小，只看相对变化）。子 Agent 静帧的等锁合计：

| 规则 | 静帧等锁 | 全体等锁 |
|---|---|---|
| 现状先来先渲 | 1.12 时 | 2.49 时 |
| 只让静帧插队 | 1.10 时 | 2.47 时 |
| 子 Agent 的整段渲染挪到合并后、照常占锁 | 4.2～32.7 时 | 大幅变差 |
| 整段渲染全部让路（只用空闲） | 0.72 时（−36%） | 1.47 时 |
| 再加上逐帧校验也让路 | 0.51 时（−55%） | 0.62 时（−75%） |

这 104 小时里锁只忙 10.3 小时，让路的 3.6 小时放得进空闲。关键不是谁渲，而是整段渲染给静帧让路。单段很长的（日落划船一段 8.7 分钟）照样只能在段间让。

改前实测基线（`anim 调度 等锁表 --到 2026-11-06T04:00:00Z`）：worktree 静帧 691 张，等锁合计 2.14 时，中位 0.04 秒，p90 25.5 秒，最长 768 秒；等的时候锁在 worktree 静帧 0.48 时、worktree render 0.45 时、worktree 逐帧校验 0.22 时手里。worktree render 401 张占锁 4.76 时，worktree 逐帧校验 147 张占锁 1.27 时。改后用 `anim 调度 等锁表 --从 <改后起点>` 比同几项；活的多少不同，比 p90、最长和「锁在谁手里」的构成，别只比合计。

## 未采用

不引入 15% 红线/黄线、不自动短作业优先、不设实验路数上限、不拆母版写锁（迁移改名工具只声明不开渲染）、不解析代理 journal、不维护板.json、不改用户 hook 或 agent-context。GPU 并发与标签页并发仍是两个不同层次，均不在本次提高。

运行中压力只告警，不保证机器不卡，也不假定系统一定替我们回收 Chrome。长让路不自动关闭原渲染会话，以免改变同页加载历史；需要释放这一路内存时由主 Agent 明确取消。旧日志缺失的机器轨迹只能标未知，回测不编造精确数字。

用法和日志协议见 `../调度.md`；旧协议退役条件见 `../待办.md`。
