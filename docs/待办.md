## engine
- 方块网格（`engine/voxel/方块网格.tsx`）：隐世之境一楼门外的狐狸石像，轮廓边上有一圈 1 像素宽的黄线，像图集取到了旁边的贴图（照原样受光也有，核对-三渲二 帧 0、6）。正交像素机位里很显眼。要查 UV 收缩（原版 uvShrinkRatio）和图集的边距。
- 光照环境（`engine/light/环境*.ts`，见 `docs/架构.md`）没做的：
  - 雨只调灯：雨丝、天色变灰（`雨天天色` 已算好没接）、云变厚、雷闪都没画。
  - 主世界画法夜里没有月亮和星星（`月相`、`星星亮度` 已算好没接）；月光比 0.1、月光色借暮色的灯色，是暂定的数。
  - 暮色画法的云只能用 `TwilightClouds` 的默认参数（它不收参数）；Photon 云的参数是模块全局的，同一画布只能有一套。
  - `Atmosphere` 太阳一动就在 CPU 上重算 2048×1024 天空贴图，时刻逐帧变的段会慢。
  - 暮色森林的云高、别的 MC 版本的公式没核对；`anim check` 还不查 `段/<段键>/环境.ts`。
- 基岩动画播放器（`engine/anim/基岩动画.ts`）没做：`animation_controllers` 状态机（现在按层手动给）、GeckoLib 控制器切换时的过渡插值（transitionLength）、`start_delay`/`loop_delay`；`'通用'` 口径没拿 GeckoLib 4 的 jar 核过；游戏里 Molang 按 float 算，这里按 double（差在 1e-6 以下）。
- 跨帧积分的动画（TLM 尾巴弹簧 parallel4，每渲染一帧推 0.01 秒）：单帧渲染拿不到前面的帧，现在用稳态解（`核对/基岩动画/尾巴稳态.ts`）。要真积分得从 0 秒推到当前帧（`播放到`），或做按帧缓存。
