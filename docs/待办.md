## engine
- 合并地形按段依赖后的一次性过期，什么时候重渲用户定，渲完删这条（画面不变，`anim film` 默认拒过期母版，之前出片要 `--允许过期`）。`把回忆拼好给你`：去 `依据` 让 45 段指纹变（`分镜.ts`、`核对/段框架示范/时间线.ts`），main 上已过期 27 段（约 110 秒），合并后 46 段（`anim stale` 报约 282 秒，4 段耗时表里没有记录）。`应力转动`：13 个地形段指纹变（`区段包位置.ts` 不再 import 版本表），这 13 段在 main 上本来就过期，全作品仍是 37 段、约 2548 秒。
- 用 `run/地形用量/` 收窄各段的 `段.地形`（穿塔、斩娜迦声明了三个包）：等全片整段重渲出准数，看 `已量帧` 覆盖全部帧再改；收窄本身让这段过期一次。
- 渲染变慢（`docs/渲染性能.md`）：Remotion 4.0.537 自带的 Chromium 157 比 4.0.530 的 149 慢。穿塔 100 帧要 82 秒，原来 54～58 秒；区段移进工人后是 63 秒。换不换浏览器等用户定，换了全片重渲。主世界地形的补水面、海草、草、远景合并还在主线程。
- 方块网格（`engine/voxel/方块网格.tsx`）：隐世之境一楼门外的狐狸石像，轮廓边上有一圈 1 像素宽的黄线，像图集取到了旁边的贴图（照原样受光也有，核对-三渲二 帧 0、6）。正交像素机位里很显眼。要查 UV 收缩（原版 uvShrinkRatio）和图集的边距。
- 光照环境（`engine/light/环境*.ts`，见 `docs/架构.md`）没做的：
  - 雨只调灯：雨丝、天色变灰（`雨天天色` 已算好没接）、云变厚、雷闪都没画。
  - 主世界画法的月亮、星星（`星月.tsx`）没和游戏截图并排对过：月亮贴图朝向、星星亮度（加的是 亮度²）、Photon 天空在夜里几乎全黑（原版午夜天是深蓝）都待对；月光比 0.1、月光色借暮色的灯色、太阳贴地平线的淡出区间是暂定的数（预览 光照环境核对 等用户定）。
  - Photon 云夜里不受月光，月亮前面的云是黑剪影（`大气/云.ts` 只按太阳打光）。
  - 暮色画法的云只能用 `TwilightClouds` 的默认参数（它不收参数）；Photon 云的参数是模块全局的，同一画布只能有一套。
  - `Atmosphere` 太阳一动就在 CPU 上重算 2048×1024 天空贴图，时刻逐帧变的段会慢。
  - 暮色森林的云高、别的 MC 版本的公式没核对。
- 基岩动画 `'通用'` 口径的 catmullrom 取点、`lerp_mode: step`、pre/post 按基岩版写法，和 GeckoLib 4 不一样（`docs/新生物.md`「和游戏对不上的已知处」）；真有 GeckoLib 4 的生物要逐帧对上时，再分一个 `'GeckoLib4'` 口径。`start_delay` 等待时、`loop_delay` 两遍之间给什么姿势是推断的，没在基岩版里核过。
- 跨帧积分的动画（TLM 尾巴弹簧 parallel4，每渲染一帧推 0.01 秒）：单帧渲染拿不到前面的帧，现在用稳态解（`核对/基岩动画/尾巴稳态.ts`）。要真积分得从 0 秒推到当前帧（`播放到`），或做按帧缓存。
