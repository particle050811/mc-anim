# 望远：把原帧里的一块用整张图原生渲出来

用户 11-15 定做：看远处细节时，渲完再放大只有几十个有效像素，看不出东西；改成像望远镜那样，照原镜头的位置、朝向和投影，只把原帧里的一个矩形用整张 4K 原生渲出来。只有 `anim still` 认，不进指纹，`anim film` 不认。

## 用法

```
anim still <段> <帧…> --to-preview <主题> --tele <块>[;<块>…] [--finer] [--truth]
```

一块写成下面两种之一，坐标都是原帧出图的像素（视频级 3840×2160，预览级 1280×720），矩形的高按原帧宽高比算，要整个落在原帧里：

- `x,y,宽`：矩形左上角和宽，如 `1460,640,480`
- `心x,心y,<n>x`：矩形中心和放大倍数，如 `1700,775,8x`

分号隔开的几块在同一次里各出一张，文件名带 `-望远-x<左>-y<上>-宽<宽>`。块后面可以再跟 `,细一级`、`,真值` 只给这一块开（同一块出两份对着看），命令行上的 `--finer`、`--truth` 对每一块都开，文件名相应带 `-细一级`、`-真值`。

| 出法 | 出来的是什么 |
|---|---|
| 默认 | 原帧那块的放大：画哪些区段、每块用哪一级、阴影、台阶并色、贴图取哪一级都照原帧算，只是像素多了 |
| `--truth` | 着色器里按像素大小做的远处简化（体素地形的台阶并色、贴图取粗一级）改照望远后的像素算：看到的是原帧每个像素里本来有什么，缩回去等于原帧超采样。查「原帧这样简化对不对」用，不是原帧那块的放大 |
| `--finer` | 体素地形的细分门槛减半，同一处比原帧细一级（已经最细的不变）。看「几何更细会怎样」用，不是原帧那块的放大 |

`--shading` 和 `--tele` 不能同时给。2D 叠层、字幕不画。

## 做法

打包时把 `engine/段/望远.ts` 加进入口（排在作品入口前），矩形经页面环境变量 `REMOTION_ANIM_TELE` 传；段的代码、inputProps、打包规则都不动（同 `--shading` 的做法，`pipeline/渲/望远.ts`）。

镜头平时还是原整帧的投影，只在 R3F 画一帧的那一段（`addEffect` 到 `addAfterEffect`，包住 useFrame 和出图）换成「裁剪 × 原投影」，画完换回。这样：

- 组件渲染时读投影的拿到原整帧：体素世界挑区段、定级别（`pickSections`、`pixelAngle`）和原帧一样。
- 画的时候读投影的拿到望远的：屏幕 AO、云从深度反推位置和画出来的像素对得上。
- 画的时候该按原整帧算的，逐个接管：

| 项 | 怎么按原帧算 |
|---|---|
| 阴影级联（按镜头视锥拟合） | `CascadedShadow.updateMatrices` 里临时换回整帧的逆投影 |
| 屏幕 AO 的采样半径上限（占屏幕比例） | 着色器里的 `SSAO_MAX_RADIUS_SCREEN` 乘倍数 |
| 点的大小（`gl_PointSize`，星星、粒子） | 顶点着色器末尾乘倍数 |
| 按屏幕像素求的导数（`dFdx`、`dFdy`、`fwidth`）：台阶并色、体素贴图取哪一级、按导数定的边宽 | 片元着色器里加宏乘倍数（`--truth` 不乘） |
| 2D 叠层、字幕、没铺满画面的画布 | 藏掉 |

后三样在 `shaderSource` 上统一改源码，不逐个材质改。1 倍（矩形 = 整帧）时什么都不改。

## 做不到的（偏差）

- **一个像素只取一个样的地方，原帧本来就是抽样**：镂空树叶按贴图透明度丢像素、方块边缘没有抗锯齿，原帧一个像素取一个样，望远缩回去是 倍×倍 个样的平均。树叶多、边多的地方块平均差最大（见验收）。
- **云**：步进起点的 4×4 网点和合成时的 4×4 平均都按望远后的像素做，云边比原帧锐、网点更细。
- **屏幕 AO**：还原法线取相邻像素、采样点吸附到像素中心，都按望远后的像素；半径上限以外的部分和原帧一样。
- **体素地形的视锥剔除、裙边**按望远的视锥（只少画看不见的，区段和级别不变）。
- **three 自带贴图采样的多级纹理级别**（隐式导数）按望远后的像素；体素地形自己用导数算级别，已照原帧。
- **线**：WebGL 的线宽恒为 1 像素，望远后相对更细。
- **按 `gl_FragCoord` 做的网点、抖动**都按望远后的像素。
- **HTML、CSS 层**：2D 叠层藏掉；垫在画布后面的图片、渐变背景不会跟着放大；没铺满整个画面的画布（画中画、界面里的小画布）不望远，一并藏掉。
- 模块一加载就把 `LevelParams.*.像素` 读走的段，`--finer` 不生效。
- 三渲二的描边和后期、在组件渲染时读投影做屏幕空间计算的特效没有逐个核对。

## 验收（飞越 1355，视频级）

望远图按面积平均缩回原尺寸，和原帧那块照认指纹的块平均差比（门槛 8×8 > 24、16×16 > 10、64×64 > 4 判「变了」，16×16 在 6～10「看一眼」）：

| 出法 | 不同像素 | 8×8 | 16×16 | 64×64 | 判 |
|---|---|---|---|---|---|
| 1 倍（矩形 = 整帧）对普通静帧 | 0 | 0 | 0 | 0 | 逐像素相同 |
| 8 倍（1460,640 宽 480） | 77% | 14.9 | 7.3 | 2.5 | 看一眼 |
| 4 倍（1570,500 宽 960） | 69% | 22.9 | 10.2 | 3.1 | 变了（16×16 超 0.2） |
| 8 倍 `--truth` | 81% | 141 | 133 | 109 | 变了（本来就不是原帧的放大） |

8 倍、4 倍差得最多的地方是树叶多的小岛和云边，是上面头两条偏差。
