# 外部复用：别的仓库引用 库/ 和 engine/

给以后的 3D MC 作品（2D MV 未定）这类不放在 `作品/` 下的仓库用。`package.json` 的 `exports` 只开子路径，不做总入口，用到哪个文件引哪个。

## 能引的

| 子路径 | 指向 | 用途 |
|---|---|---|
| `mc-anim/库/<类>/<文件>.tsx` | `库/` | 模型、角色、生物、物品、界面、特效组件 |
| `mc-anim/engine/<目录>/<文件>.ts` | `engine/` | 贴图读取（`engine/model/贴图.ts`）、声音、骨架、体素等 |
| `mc-anim/接入/webpack` | `pipeline/资产/webpack.ts` | Remotion 打包改写 `webpack改写(本仓库根)` |
| `mc-anim/接入/缓存名` | `pipeline/资产/缓存名.ts` | `稳定缓存名(改写)`：套在最外层，webpack 缓存目录名不随资产锁变 |
| `mc-anim/接入/资产锁` | `pipeline/资产/资产锁.ts` | `读作品资产锁`、`解析资产`：自己配打包器时用 |
| `mc-anim/接入/esbuild`、`mc-anim/接入/别名` | 同名文件 | esbuild 插件、别名表（库/、engine/ 内部只用相对路径，外部不用配别名） |
| `mc-anim/接入/资产模块` | `资产模块.d.ts` | `asset:*` 的类型声明 |

文件名带后缀写，和仓库里一样；导出名是文件里的英文名，例如 `import { Diamond } from 'mc-anim/库/物品/钻石.tsx'`。导出的是 TS 源码，没有预编译的 `.js`/`.d.ts`。

## 怎么加依赖

- 推荐本地路径：`"mc-anim": "file:../mc-anim"`。npm 建软链，Node 按真实路径跑，`.ts` 能直接被 Node 类型擦除执行；用的就是这份检出的 `anim.local.toml` 和数据根。
- git 依赖（`git+ssh://…/mc-anim.git#<提交>`）能装，但 Node 不对 `node_modules` 里的 `.ts` 做类型擦除，`接入/*` 在 Node 里直接 import 会失败；只经打包器引组件可以。没验过，要用先试。
- `remotion`、`@remotion/*`、`react`、`three`、`@react-three/fiber` 的版本和 mc-anim 的 `package.json` 一字不差（Remotion 各包必须同版本；three 只能有一份）。

## 类型检查

外部 tsconfig 要 `moduleResolution: "bundler"`、`allowImportingTsExtensions`、`jsx: "react-jsx"`、`strict`，入口里加：

```ts
/// <reference types="mc-anim/接入/资产模块" />
/// <reference types="@react-three/fiber" />   // <group>、<mesh> 等 JSX 类型
```

## asset:<id> 怎么解析

库/ 里的贴图、字体、声音写成 `import x from 'asset:<id>'`，id 查资产锁（`mc-anim/assets/资产锁.json` 并上外部仓库根的 `资产锁.json`，没有就只用共用的），字节在 mc-anim 数据根的 `store/`、`私有/`。

- Remotion（webpack）：`remotion.config.ts` 里 `Config.overrideWebpackConfig(webpack改写(本仓库根))`。本仓库根要有 `清单.ts`（可以只写 `export {};`，有 `求解入口` 就照作品的写法注入求解指纹）。它同时把 npm 包先指向 mc-anim 的 `node_modules`，保证 three、remotion 只有一份。
- 自己配（esbuild 等）：最小做法是一个插件，`asset:<id>` → `解析资产(id, 读作品资产锁(根))` 得到 `{ 条目, 文件 }`，按 `条目.后缀` 选 loader（png 内联成 data URI，音频、bin 出成文件；ogg 要解成 wav 的话借 `webpack.ts` 的 `ogg解码loader`）。
- 缺 id 或字节不在：报错里写 `anim assets add`，在 mc-anim 里登记入库后再打包。

10-22 用一个临时外部工程验过：只引 `库/物品/钻石.tsx`、`库/界面/伤害数字.tsx`，tsc 通过，esbuild 按上面的插件打出单文件，`webpack改写` 在打成 CJS 的配置里也能找到代码根。
