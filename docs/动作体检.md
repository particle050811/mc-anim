# 可复用的动作体检

`./anim --work 亚波伦不放水 verify motion --video <正片.mp4> --out <新报告.json> --trace 1820-1919`。不指定视频就只验动作；`--trace` 可选，按**整片、零基、闭区间**保存最终骨点，能和解码帧一一对齐。超限返回 1。整部常规 `film` 对已登记的作品先验动作再渲；局部试拍不因此受阻。成片封装默认核每个视频包的显示时间，失败不把临时文件改名为正片。

## 新作品怎样接

1. 在作品根建 `动作体检.ts`，默认导出 `MotionProfile`。这是只给验收的注册入口，和正片用同一套段长、镜头表、时间映射、姿态层与骨骼正解；不要复制一套看起来差不多的关键帧。输入是整数输出帧；世界时间、原舞时间、慢放区间都从它推导，不依赖渲染顺序。
2. 用实际剪辑决定 `shot`，不能用段号代替：本片 F793→794 换段但不切镜；F578→579 真切，可瞬移。同镜把**根位**（世界格）、**掌脚**（去除演员整身位移后的模型场景格）和**机位**分开，机位的视线方向另作朝向轨（`directions`）。速度阈值为格／秒；脚本设计的高速冲刺只给相应镜头放行。连续动作可启用 `checkAlternation`，有意定格不用 `maxHoldSec`。加速度、骤降再起见下文「同一镜里的突变」。测经过 IK、附加修正、父骨变换后的点，不测原始欧拉角的数值差。
3. 对会互穿的具体部件登记碰撞对。本片复用 `bindShellProbe`：在骨盆局部坐标里用 45 层、每层 48 条射线比较衣物与腿鞋的真实三角面，开口以下允许正常露脚。这个方法适合围住身体的裙壳，**不是任意网格的全碰撞检测**；领带、武器、翅膀或额外饰物要另配对应探针。验收至少留一个注入错误姿势、确实会失败的用例。
4. 体检给出镜头、问题连续区间、峰值帧和量纲。录像通路读取解码后的真实 PTS，并对每张 160×90 灰度缩图取摘要。缩图相同是复查线索，不是掉帧；缩图不同也不能证明每根骨都动了。`--trace` 看异常两侧，配原生望远或半速回放再决定是动作、镜头还是封装。

## 同一镜里的突变

只在同一镜里查（按 `shot` 认，不按段：段缝不切镜照样连着查，切镜清历史、可以瞬移）。`MotionSample.directions` 放朝向轨（如机位的 `tgt − pos`，不必归一），和点轨共用 `tracks` 的配置，量纲换成度/秒、度/秒²；它查镜头一帧里甩一下、摇着摇着顿住，机位位置平稳但视线在拧的病只有它看得出。每条规则都是默认值 + 按镜放宽（`shot*`），没配的规则不查。

| 规则 | 配置 | 量的是什么 | 用来抓 |
|---|---|---|---|
| 速度 | `maxSpeed`、`shotSpeed` | 相邻两帧位移 × fps | 镜内跳位、太快 |
| 加速度 | `maxAccel`、`shotAccel` | 相邻两帧速度**矢量**之差 × fps（方向急转也算） | 一帧里跳一下（跳 d 格，加速度约 d × fps²）、速度断崖、急刹、分段函数的折角 |
| 骤降再起 | `dip: { minSpeed, maxDepth, windowSec = 1 }`、`shotDipDepth` | 降幅 = 1 − 这一帧速度 ÷ 前后 `windowSec` 内各自最快里较小的那个；两侧最快都到 `minSpeed` 才算 | 先快、中途几乎停住、再快：e98e94cc 修的 2-03 绕两次（朝向 356 → 12 → 55 度/秒，降幅 0.79） |
| 停顿秒数、隔帧停走 | `maxHoldSec`、`shotHoldSec`、`checkAlternation` | 见上 | 定住太久、30→60 的重复帧 |

- 单峰的缓入缓出没有降幅（升的时候前面最快就是自己，降的时候后面最快就是自己），不会误报；一头停住不再起（刹停、起步）也不算。来回摆的轨（掌、脚、舞）每个来回都是骤降再起，不配 `dip`，只用加速度拦一帧跳位。
- 有意的定格、蓄力、打击停顿、一下下冲中间的急刹，按镜给 `shotDipDepth: { 镜: 1 }` 放行（降幅最大是 1）；加速度同理给 `shotAccel`。放行写清出处（分镜、用户哪天看过）。
- 阈值按真实数据定：在 main 上把各规则放到很宽跑一遍，看各轨各镜的峰值和最差那几帧，默认值取在正常镜头之上、已知的病之下。新规则查出来、用户已经看过的现状（元规则 1），只按镜放到刚好过现状，注释写「现状」和帧号、等用户定，不要把默认值整体抬高。
- 回归：改了规则，拿修过病的提交前后各跑一遍（`pipeline/环境/开worktree.ts` 的 `openTempCheckout` 开临时检出、拷入新的 `engine/anim/动作体检.ts` 和作品的 `动作体检.ts`，跑 `verify motion`），病的那边要报、修好的那边不报。本片：`e98e94cc^` 报 2-03 F627–655 骤降再起 0.79（还有朝向 359 度/秒、加速度 4125），`e98e94cc` 不报。
- 查不出的：编排上不合理但每一帧都连续的（a031002d 修的「召唤出来以后还往后退」「到位后像罚站」），要按剧情判断往哪走、该不该站着，不是连续性规则管的；焦距、roll 还没采。

`engine/anim/动作体检.ts` 和作品的 `动作体检.ts` 只给验收用，渲染代码不 import，改它们不动段指纹（`anim stale` 照旧最新）。

调动作时先固定约束（握哪只手、什么时候伸直、什么时候放开、允许哪些接触），再叠风摆、衣物和镜头。不要把每一帧做成独立姿势，也不要把已设定的快速动作全局降速来让检查通过。
