# 可复用的动作体检

`./anim --work 亚波伦不放水 verify motion --video <正片.mp4> --out <新报告.json> --trace 1820-1919`。不指定视频就只验动作；`--trace` 可选，按**整片、零基、闭区间**保存最终骨点，能和解码帧一一对齐。超限返回 1。整部常规 `film` 对已登记的作品先验动作再渲；局部试拍不因此受阻。成片封装默认核每个视频包的显示时间，失败不把临时文件改名为正片。

## 新作品怎样接

1. 在作品根建 `动作体检.ts`，默认导出 `MotionProfile`。这是只给验收的注册入口，和正片用同一套段长、镜头表、时间映射、姿态层与骨骼正解；不要复制一套看起来差不多的关键帧。输入是整数输出帧；世界时间、原舞时间、慢放区间都从它推导，不依赖渲染顺序。
2. 用实际剪辑决定 `shot`，不能用段号代替：本片 F793→794 换段但不切镜；F578→579 真切，可瞬移。同镜把**根位**（世界格）、**掌脚**（去除演员整身位移后的模型场景格）和**机位**分开。速度阈值为格／秒；脚本设计的高速冲刺只给相应镜头放行。连续动作可启用 `checkAlternation`，有意定格不用 `maxHoldSec`。测经过 IK、附加修正、父骨变换后的点，不测原始欧拉角的数值差。
3. 对会互穿的具体部件登记碰撞对。本片复用 `bindShellProbe`：在骨盆局部坐标里用 45 层、每层 48 条射线比较衣物与腿鞋的真实三角面，开口以下允许正常露脚。这个方法适合围住身体的裙壳，**不是任意网格的全碰撞检测**；领带、武器、翅膀或额外饰物要另配对应探针。验收至少留一个注入错误姿势、确实会失败的用例。
4. 体检给出镜头、问题连续区间、峰值帧和量纲。录像通路读取解码后的真实 PTS，并对每张 160×90 灰度缩图取摘要。缩图相同是复查线索，不是掉帧；缩图不同也不能证明每根骨都动了。`--trace` 看异常两侧，配原生望远或半速回放再决定是动作、镜头还是封装。

调动作时先固定约束（握哪只手、什么时候伸直、什么时候放开、允许哪些接触），再叠风摆、衣物和镜头。不要把每一帧做成独立姿势，也不要把已设定的快速动作全局降速来让检查通过。
