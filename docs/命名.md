# 命名

依据：段命名方案（旧项目 `预览/1021-0905-段命名方案/方案.md`）、新项目方案第三节第 1 条，用户 10-21 拍板。

## 路径语言

- **结构层用英文 ASCII**：顶层目录和固定层级，如 `pipeline/`、`engine/`（`库/`、`作品/` 两个顶层是用户定的中文名，例外）、`assets/registry/`、`作品/应力转动/认可/`。理由：npm、uv、Gradle 的包名只认 ASCII；ForgeGradle 在 Windows 默认 GBK 下处理非 ASCII 路径容易出错。
- **实体层用中文**：场、段、资产 id、台词 id、角色名，如 `作品/应力转动/段/6-斩娜迦/`。
- 文件名要在 Windows 上合法（不用 `<>:"/\|?*`、不以空格或点结尾），`anim check` 会查。

## 代码标识符

用户 11-15 定代码改英文（预览 `1115-1230-英文命名-对照表草稿`、`1115-1448-英文命名-拼名样例`）：

- 变量、函数、类型、属性一律英文，名字说清内容，不用序号，不逐字直译。核心词的固定译法在改名工具的对照表里，同一个词全仓一种译法。
- 原创角色用拼音（`liYing`、`jiuHu`、`yaBoLun`）；MC 和模组的东西用游戏的英文注册名（`naga`、`lich`、`tuff`）。
- 时间线事件：讲故事的按发生了什么起名（`reunionGaze`），跟着歌词走的保留句号（`line4VocalIn`）。
- 还是中文的有三类：
  - 写在盘上数据里的键（运行日志、交付元数据、取材输出、模型骨骼名这类），等连数据一起迁移；
  - 取值和画面上的字（音效 cue 名、字幕、核对视图名）；
  - 上面「路径语言」里的实体（场键、段键、资产 id、台词 id、规矩 id）。
- 11-16 的批量改名工具和盘键迁移工具用完已删，要再用从 git 历史取（`git show 5df81a4c:pipeline/改名/main.ts`、`pipeline/迁移/`）。改名工具的坑：会把恰好同名的数据名、读 store 字节的类型键、代码字符串里的中文文件名一起改掉，tsc 拦不住，改完要真渲核对。
- 不新增中文标识符：`anim check idents` 查语法树里的标识符（字符串、注释、文件名不算），现有的名字冻在 `pipeline/检查/中文标识符基线.txt`，只许减少；改掉了的名字照提示从表里删。按名字记，新代码重用表里已有的中文名查不出，起名时自己守。
- `anim` 的命令、子命令、参数也是英文（`anim sched watch`、`--to-preview`），取值（段键、场键、作品名、主题）照旧中文；环境变量不改。旧的中文写法不留别名，敲了报「改名了，用 xxx」、退出 2，旧→新只记在 `pipeline/cli/旧名.ts` 一处（用户 11-15 定）。新命令、新参数照这张表里的词拼。
- 环境变量名用英文（现有的 `ANIM_*`、`REMOTION_ANIM_*`、`PKGS` 都是）。中文名在 zsh 里传不进来：`中文名=值 命令` 和 `export 中文名` 会把名字的字节写坏（zsh 的毛病，四分之三的常用汉字中招），程序按原名读不到，Node 一起 Worker 线程还会段错误退出 139。`anim` 入口查到这种名字就报错退出 2（`pipeline/环境/环境变量名.ts`，来龙去脉在文件头）；一定要中文名就写 `env 中文名=值 ./anim …`。

## 键

| 对象 | 规则 | 例 |
|---|---|---|
| 场键 | `<章>-<场名>`，不带场号 | `6-暮色森林`、`7-黑暗监守` |
| 段键 | `<章>-<段名>`，是段的永久身份。段名写内容、全片唯一，只用汉字、字母、数字（Remotion 的 Composition id 只认 `[a-zA-Z0-9-一-鿿]`）。Composition id、`作品/应力转动/段/<段键>/`、母版缓存都用它 | `6-斩娜迦`、`7-五万血` |
| 编号 | `<章>-<两位序号>`，按 `作品/应力转动/清单.ts` 的顺序现算，插段就会变。只出现在每次重新生成的产物里，不当键用 | `6-02 斩娜迦` |
| 台词 id | `<章>-<角色>-<短名>`，章内唯一，和段解耦；合段、拆段都不改 | `6-李樱-不值一提` |
| 资产 id | `<类>/<名>`，代码里只写 id，不写路径 | `实体/监守者`、`网格/古城4x/<块>`、`音效/entity.warden.roar`、`配音/7-刘心忠-不可能` |
| 规矩 id | 中文短词 | `打击停顿`、`马人立` |
| 变体、核对 | `<段键>-<用途>`；不属于某一段的核对写 `核对-<名>` | `6-羊毛搜刮-关键帧`、`核对-冒烟` |
| 母版（切片） | `cache/母版/<作品>/<段键>/<画面指纹前 16 位>.mp4`、`<声音指纹前 16 位>.wav`，旁边放 `.指纹.json` | |
| 预览文件夹 | `预览/<月日-时分>-<主题>/`，时间用 UTC | `1021-0925-新项目方案` |
| 交付 | `交付/<作品>/<UTC 月日-时分>-<名>/`，名默认是 film 的选择器 | `交付/应力转动/1021-1200-6-7/` |

- 跟用户说话、写提交信息、写记忆时用段名，可以带上编号，如「6-08 城墙瞭望」。不写旧段号；要提旧号就查 `作品/应力转动/旧名.tsv`。
- 场和拍是剧本里的说法，不进段键。清单里记 `场`（跨场的段记开头那场）；段里的拍和时间线窗口用段内的名字（`穿塔`、`镜1`）。

## 旧名

- `作品/应力转动/旧名.tsv` 列：类别、旧名、新键、备注。类别有：场号、段号、Composition、拍号、段名、台词、已删段、已删台词。
- 旧名**永不复用**：新段名、新台词 id 都不能等于表里任何一个旧名，除非那一行的新键就是它自己。`anim check` 会查。
- 改名、删段、删台词时，往表里追加一行；不删旧行。

## 增删段

| 情况 | 怎么做 |
|---|---|
| 加段 | 在 `作品/应力转动/清单.ts` 按播放位置插一行，建 `作品/应力转动/段/<段键>/`。后面的编号自动顺延，不用改任何目录名 |
| 合段（几个不切的镜头合成一段） | 起一个按内容取的段名，或者沿用主要那段的名字。被合进来的段变成新段里的拍，旧段键记进旧名表。台词 id 不动 |
| 拆段 | 名字还贴切的那一半沿用原段键，另一半起新名 |
| 删段 | 删掉清单那一行，代码直接删；要留对照就渲成 mp4 放进数据根 `archive/`。段名记进旧名表 |
| 改名 | 段目录、清单、`作品/应力转动/认可/<平台>/<段键>.toml` 一起改；数据根里 `cache/母版/<作品>/<段键>/` 跟着改名，不用重渲。旧名记进旧名表。段名是永久身份，没有充分理由不改 |
| 跨场 | 只改清单的 `场` 字段 |
