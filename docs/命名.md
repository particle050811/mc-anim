# 命名

依据：段命名方案（旧项目 `预览/1021-0905-段命名方案/方案.md`）、新项目方案第三节第 1 条，用户 10-21 拍板。

## 路径语言

- **结构层用英文 ASCII**：顶层目录和固定层级，如 `content/`、`pipeline/`、`assets/registry/`、`verify/accepted/`。理由：npm、uv、Gradle 的包名只认 ASCII；ForgeGradle 在 Windows 默认 GBK 下处理非 ASCII 路径容易出错。
- **实体层用中文**：场、段、资产 id、台词 id、角色名，如 `content/段/6-斩娜迦/`。
- 文件名要在 Windows 上合法（不用 `<>:"/\|?*`、不以空格或点结尾），`anim check` 会查。

## 键

| 对象 | 规则 | 例 |
|---|---|---|
| 场键 | `<章>-<场名>`，不带场号 | `6-暮色森林`、`7-黑暗监守` |
| 段键 | `<章>-<段名>`，是段的永久身份。段名写内容、全片唯一，只用汉字、字母、数字（Remotion 的 Composition id 只认 `[a-zA-Z0-9-一-鿿]`）。Composition id、`content/段/<段键>/`、母版缓存都用它 | `6-斩娜迦`、`7-五万血` |
| 编号 | `<章>-<两位序号>`，按 `content/清单.ts` 的顺序现算，插段就会变。只出现在每次重新生成的产物里（单段渲染文件名、剪辑包片段名），不当键用 | `6-02 斩娜迦` |
| 台词 id | `<章>-<角色>-<短名>`，章内唯一，和段解耦；合段、拆段都不改 | `6-李樱-不值一提` |
| 资产 id | `<类>/<名>`，代码里只写 id，不写路径 | `实体/监守者`、`网格/古城4x/<块>`、`音效/entity.warden.roar`、`配音/7-刘心忠-不可能` |
| 规矩 id | 中文短词 | `打击停顿`、`马人立` |
| 变体、核对 | `<段键>-<用途>`；不属于某一段的核对写 `核对-<名>` | `6-羊毛搜刮-关键帧`、`核对-冒烟` |
| 母版 | `cache/母版/<段键>/<指纹前 16 位>.mkv`，旁边放 `.指纹.json` | |
| 预览文件夹 | `预览/<月日-时分>-<主题>/`，时间用 UTC | `1021-0925-新项目方案` |
| 交付 | `交付/<UTC 月日-时分>-第<首章>-<末章>章/` | `交付/1021-1200-第6-7章/` |

- 跟用户说话、写提交信息、写记忆时用段名，可以带上编号，如「6-08 城墙瞭望」。不写旧段号；要提旧号就查 `docs/旧名.tsv`。
- 场和拍是剧本里的说法，不进段键。清单里记 `场`（跨场的段记开头那场）；段里的拍和时间线窗口用段内的名字（`穿塔`、`镜1`）。

## 旧名

- `docs/旧名.tsv` 列：类别、旧名、新键、备注。类别有：场号、段号、Composition、拍号、段名、台词、已删段、已删台词。
- 旧名**永不复用**：新段名、新台词 id 都不能等于表里任何一个旧名，除非那一行的新键就是它自己。`anim check` 会查。
- 改名、删段、删台词时，往表里追加一行；不删旧行。

## 增删段

| 情况 | 怎么做 |
|---|---|
| 加段 | 在 `content/清单.ts` 按播放位置插一行，建 `content/段/<段键>/`。后面的编号自动顺延，不用改任何目录名 |
| 合段（几个不切的镜头合成一段） | 起一个按内容取的段名，或者沿用主要那段的名字。被合进来的段变成新段里的拍，旧段键记进旧名表。台词 id 不动 |
| 拆段 | 名字还贴切的那一半沿用原段键，另一半起新名 |
| 删段 | 删掉清单那一行，代码直接删；要留对照就渲成 mp4 放进数据根 `archive/`。段名记进旧名表 |
| 改名 | 段目录、清单、`verify/accepted/<平台>/<段键>.toml` 一起改；数据根里 `cache/母版/<段键>/` 跟着改名，不用重渲。旧名记进旧名表。段名是永久身份，没有充分理由不改 |
| 跨场 | 只改清单的 `场` 字段 |
