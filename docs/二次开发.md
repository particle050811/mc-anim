# 二次开发

写给想改这几部作品、或者用这套管线做自己作品的人。先照 [从零渲染.md](从零渲染.md) 走到「先渲一张静帧」能出图，再看这里。

## 先知道这几件事

- **命名全是中文。** 目录的结构层（`作品/`、`engine/`、`pipeline/` 这些）用英文，场、段、资产 id、台词 id、角色名、函数名、变量名大多是中文。规则在 [命名.md](命名.md)。
- **素材按 sha256 管。** 代码里不写素材文件路径，写资产 id（比如 `贴图/角色/九胡`）；字节放在 Git 外的数据根，资产表登记来源、许可，资产锁记 sha。见 [assets/README.md](../assets/README.md)。
- **每段有指纹。** 段的指纹由它用到的代码、素材、设置算出来，变了才重渲；`anim film` 只补过期的段。所以改一处代码，只有用到它的段会重渲。
- **出片只有一条路：`anim film`。** 不要用 `npx remotion render`；静帧用 `anim still`，实时预览用 `anim studio`。它们会按作品取根、算指纹、排队过资源闸。
- **仓库根的 `CLAUDE.md`** 是作者给自己的 AI 助手定的工作纪律（中文回复、worktree、预览夹、提交方式）。你用 AI 助手改这个仓库时，它会自动读到；那些规矩是作者的习惯，你的分支里可以改。

## 改一处、看一眼、出片

以「把回忆拼好给你」第 2 章的 `2-祭坛召唤` 为例（Windows 把 `./anim` 换成 `.\anim.cmd`）：

1. 找到段：`作品/把回忆拼好给你/段/2-祭坛召唤/`，画面在里面的 `.tsx`。
2. 改完出一帧看看：

   ```
   ./anim --作品 把回忆拼好给你 still 2-祭坛召唤 60 --到预览 改字
   ```

   PNG 在 `预览/<UTC 日期时间>-改字/`。几帧一起看就多写几个帧号：`still 2-祭坛召唤 0 30 60`。
3. 要拖时间线、边改边看：`./anim --作品 把回忆拼好给你 studio`，浏览器里开 Remotion Studio。
4. 看哪些段因为这次改动过期了：`./anim --作品 把回忆拼好给你 stale`。
5. 出片：`./anim --作品 把回忆拼好给你 film 2`，只重渲过期的段。只出这一段也行：`film 2-祭坛召唤`。选择器还认场键，有的段键和场键同名（比如 `2-选择世界` 那一场有 3 段），`still` 对上不止一段会报错，换一个段或看 `anim help`。
6. 交之前跑检查：`./anim --作品 把回忆拼好给你 check`（类型、结构、清单、台词、资产登记都查）。`--快` 跳过类型检查。

只是重构、提速、搬代码，按理不改画面的：`./anim 认指纹 <选择器> --理由 "…"` 抽帧和旧切片比，都一样就沿用旧切片，不用整段重渲（[决策/0013-认指纹.md](决策/0013-认指纹.md)）。

## 新作品、新段

```
./anim new work 我的短片                       照模板起一部作品，带一个能渲的 核对-起步
./anim --作品 我的短片 new seg 1-开场 --场 1-山顶   加一段，排进清单末尾
./anim --作品 我的短片 cues                     按段里的声音 cue 生成声音表（still、film、studio 开头也会自动跑）
```

段框架怎么写（时间线、窗口、声音 cue、画面）见 [新段.md](新段.md)，示范在 `作品/把回忆拼好给你/核对/段框架示范/`。新生物、新模型见 [新生物.md](新生物.md)。

作品默认进 Git。不想公开的作品，在 `.gitignore` 加 `/作品/<名>/`，或者放到 `作品/` 外面、在 `anim.local.toml` 的 `[works]` 里登记（模板见 `anim.local.toml.example`）。

## 加素材

```
./anim --作品 我的短片 assets add 贴图/角色/某人 某人.png
```

- 先在资产表里登记一条（共用的写 `assets/registry/<类>.toml`，只有这部作品用的写 `作品/<名>/资产表/<类>.toml`），写清 `来源`、`许可`、`可见性`；`assets add` 照登记在哪一侧写资产锁、把字节按 sha 放进数据根。
- `可见性`：`公开`、`提取`、`发布` 的会随 Release 发；`私有` 的不发、字节只放数据根 `私有/`，别人拉不到，用到它的段别人就渲不了。
- 字段和规则见 [assets/README.md](../assets/README.md)、[决策/0002-资产标准.md](决策/0002-资产标准.md)。

## 从游戏、模组里取材

模型、贴图、动作、音效尽量照 jar 里的原样导出，不手画：

- `sourcing/jars.toml` 登记每个 jar 的版本、sha256、许可、下载地址；`sourcing/extract.toml` 写每件产物怎么从 jar 导出。
- `./anim extract <配方>` 导出并核 sha；`--登记` 把新产物写进资产表和资产锁；`--下载` 取官方映射这类不许再分发、要本机自取的文件。
- 要开游戏取数据的（群系色、方块表、法术录制）走取材 mod：`./anim mcai …`、`./anim gamedata 导出`，要 Prism Launcher、JDK 17 和正版 Minecraft，见 [游戏导表.md](游戏导表.md)、[决策/0016-法术录制.md](决策/0016-法术录制.md)。

## 地形

地形从 Minecraft 存档烘成区段包再渲染。世界的来历写在 `sourcing/worlds/<世界>.toml`，不开游戏改地形写在同名的 `.编辑.toml`（fill、setblock、clone、摆结构）。只渲染的话 `assets pull` 下来的地形包就够；要改地形、重烘，得有取材服务端和存档（`ANIM_GAME`）。

```
./anim world list                                   列世界声明、要烘的包、登记的版本
./anim world bake <世界> [--包 <名>] [--不登记]       读存档、套编辑、烘区段包、登记版本
./anim world map <世界> <x1> <z1> <x2> <z2>          俯视图（PNG，带坐标网格）
./anim world slice <世界> x|z <位置> <起> <止>        切面图
./anim world pregen <世界>                           打印预生成（Chunky）命令
```

详见 [世界.md](世界.md)。

## 配音

台词的唯一来源是作品的 `台词.toml`。配音、口型由 `anim voice` 出，要 [uv](https://docs.astral.sh/uv/) 和 TTS、对齐模型（位置写进 `anim.local.toml`）。作者的 TTS 走自己的 image-flow 工具，别人的机器上没有，`anim voice backends` 会列出缺什么。已经定稿的配音都在 Release 里，只渲染不用管这一节。

```
./anim voice backends                       有哪些 TTS 后端、这台机器上缺什么
./anim voice gen <台词 id> --dry-run        看要发给后端的请求，不合成
./anim voice gen <台词 id>                  出候选，进数据根 run/草稿/配音/
./anim voice use <台词 id> <候选.wav>       定稿：裁静音、拉响度、登记资产、写回 台词.toml
./anim voice lip [前缀]                     重出口型
```

## 发你自己的版本

想让别人也能渲你改过的作品：

1. Fork 本仓库，把三部作品 `作品/<名>/随发布.toml` 里的 `仓库` 改成你的 `<用户名>/<仓库名>`。
2. 装 [GitHub CLI](https://cli.github.com/) 并 `gh auth login`。
3. 每部作品跑一次 `./anim --作品 <名> assets pack --上传`：照当前代码算出每段要的字节和地形包，打成 tar，传到你仓库的 Release，并改写 `发布锁.json`。
4. 提交 `发布锁.json`，推送。别人 clone 你的仓库以后照 [从零渲染.md](从零渲染.md) 就能渲。

附件名按内容算，内容没变的附件不重传；做法见 [决策/0006-挂Release发字节.md](决策/0006-挂Release发字节.md)、[决策/0017-全部公开.md](决策/0017-全部公开.md)。

## 画面会不会和作者一模一样

- Mac 上和作者是同一个后端，可以逐字节相同。
- Windows 默认用 Vulkan，同一台机器渲两遍逐帧相同，和 Mac 比 PSNR 34～50（11-14 实测，近处草多的画面低），并排看不出差别；草丛、小花、草方块顶面这些带随机偏移和朝向的东西会因显卡不同而不同。要换后端设 `ANIM_GL`（`anim env` 列出所有配置项）。
