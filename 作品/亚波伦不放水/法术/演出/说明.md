# 法术演出：怎么加一个法术

71 个进齐放的法术各做一个「出手后」的画面。名单和分组在 `分组.ts`（样板 3 个，甲 23、乙 15、丙 14、丁 16，按 `法术表.ts` 的难度估工作量是 35、34、34、36）。各组只动自己的文件，不会改到同一行。

## 要建什么

以法术「火球」（注册名 `fireball`，在甲组）为例，建两个文件、各加两行登记：

1. `法术/火球.元.ts`：元数据，纯模块（段.ts 排声音、算时长时要引，不能引 `asset:`、React、three）。

   ```ts
   import { 定义法术元 } from '../接口.ts';

   export default 定义法术元({
     id: 'fireball',          // 法术表.ts 的 注册名
     长秒: 3,                 // 从出手到画面上什么都不剩
     命中秒: 1.2,             // 打到史蒂夫的时刻；没有命中一说的不写
     声音: [{ 资产: '音效/诡厄巫法/goety.xxx', 秒: 0 }],   // 没有就 []；音量、音高照游戏 playSound 的参数写
   });
   ```

   飞多久看距离的（弹道类）另给 `时长: (起点, 目标) => ({ 长秒, 命中秒 })`，`长秒`、`命中秒` 写核对段摆法 `时长([-10, 0, 7], [0, 0, 0])` 下的数；命中时才响的声音写 `从命中: true`（`秒` 从命中那一刻算）。照 `法术/灵魂束.元.ts`。

2. `法术/火球.tsx`：画面，默认导出 `定义法术演出(元, 组件)`。

   ```tsx
   import React from 'react';
   import { 定义法术演出 } from '../定义.tsx';
   import type { 法术演出属性 } from '../接口.ts';
   import 元 from './火球.元.ts';

   const 火球: React.FC<法术演出属性> = ({ 秒, 起点, 目标, 种子 }) => { … };
   export default 定义法术演出(元, 火球);
   ```

   属性四个，都一样：`秒`（出手后的秒，带小数，宿主只在 `[0, 长秒)` 里画）、`起点`（盘上那一格或杖尖）、`目标`（史蒂夫脚底中心）、`种子`。坐标是场景坐标（Z 朝上：x 东、y 北、z 上，单位格）。组件里不调 `useCurrentFrame`，也不用 `Math.random`：同样的属性每次要画出同一帧，随机数用 `rng(种子)`（`@engine/model/parts.tsx`）。游戏里的刻 = `秒 × 20`。

3. 登记：在自己组的 `组/甲.ts` 加 `import 火球 from '../法术/火球.元.ts';` 并放进数组，`组/甲.tsx` 加 `import 火球 from '../法术/火球.tsx';` 并放进数组，两边顺序一样。`分组.test.ts` 会查：只登记了自己名下的、两张表对得上、`法术/` 下每个文件都进了表。

文件头写出处（读了哪些类、渲染器怎么摆、粒子常数），和「没做」的清单。一个法术专用的中间件就放在它自己的 `.tsx` 里；两个以上法术共用的（比如同一种粒子类）放 `零件/` 下新开文件，别改已有零件的行为。

## 怎么看

核对段 `核对-法术演出` 照 `元表.ts` 自动给每个法术排一槽 120 帧，不用改它。槽的顺序：样板、甲、乙、丙、丁，组内照各组表的顺序。第 i 个（从 0 数）法术：

- 第 `i × 120` ～ `i × 120 + 59` 帧：全景（起点在左上空中、史蒂夫在右下都入画）；
- 第 `i × 120 + 60` ～ `i × 120 + 119` 帧：近景（对着史蒂夫）；
- 两半各把法术从出手到结束走一遍：法术第 t 秒在全景的第 `i × 120 + round(t ÷ 长秒 × 60)` 帧，近景再加 60。

画面左上角印着第几个、法术名、出手后几秒、槽起帧。别的组合并进来后 i 会变，以画面上印的为准。

```
./anim --作品 亚波伦不放水 still 核对-法术演出 <帧…> --到预览 工作-<主题> --逐帧
npx vitest run 作品/亚波伦不放水/法术
```

## 零件（`零件/`）

| 文件 | 给什么 | 对应游戏里的 |
|---|---|---|
| `材质.ts` | `面材质(图, {混合, 色, 透明度, 重复})`、`贴图()`、`十六进制色()`；混合三种：镂空、半透明、加色 | 各种 RenderType 的混合方式，都不受场景光 |
| `面片.tsx` | `面片们`（同一张贴图的一批朝镜头方片，可转角、可不等宽高、可取局部 uv）、`面片`、`序列帧(帧们, 序号, 循环)` | 粒子方片、ThrownItemRenderer |
| `粒子.tsx` | `贴图粒子`（模组粒子类通用模拟：填一个 `粒子类` 加一张 `粒子出生` 表）、`服务端撒`（sendParticles 的散布）、`原版粒子初速`；转出口库里的 `VanillaParticles`（原版 flame、smoke、poof 等已照抄的） | TextureSheetParticle 子类；原版粒子底座在 `@库/特效/粒子面片.tsx`、`@库/特效/原版粒子.tsx` |
| `弹道.ts` | `直线`、`火球道`（AbstractHurtingProjectile）、`抛物线`、`抛到`（反解初速）、`追踪`、`弹道位置`、`弹道方向`、`命中刻`、`朝向角`，和向量小函数 | 各类弹射物的 tick()，一刻一刻走再插值 |
| `束.tsx` | `束`（两点之间绕轴交叉的几片，贴图沿长度滚）、`带`（沿一串点铺的条，宽的方向自己给） | 信标光柱、守卫者激光、CorruptedBeam；尾迹 renderTrail |
| `电弧形.ts`、`电弧.tsx` | `电弧`、`电弧预设`（shock、thunderBolt、lightningBolt）、`生成电弧` | LightningParticleOptions（Mekanism 的 BoltEffect） |
| `地面贴花.tsx` | `地面贴花`（平躺在地上的一张贴图） | 预警圈、冲击波环、法阵 |
| `实体.tsx` | `MC空间`（里面用游戏坐标）、`取模型`、`模型件`（画法：镂空、半透明、发光、加色；`姿态` 按部件名改）、`度` | 实体渲染器：照 render() 里的 PoseStack 一层层套 group，写法见文件头 |

实体模型：`import 模型数据 from 'asset:模型/法术/goety/<类名>'`，再 `取模型(模型数据, '<类名>')`；贴图 `import 图 from 'asset:贴图/法术/goety/<textures 下的路径>'`，用 `png(图)`（`@engine/model/贴图.ts`）。素材的 id 规则和每个法术用到哪几件见 `../../素材清单.md` 第 2 节；缺的往 `sourcing/extract.toml` 对应配方里加，`anim extract <配方> --登记`。模型的动作（setupAnim 里按 ageInTicks 算的）要照源码抄成 `姿态`。

三个样板各是一类的写法：`灵魂束`（弹道：模型 + 尾迹带 + 命中粒子，时长随距离）、`幽灵火`（落在地面：模型两遍画法 + 序列帧贴图 + 持续冒的粒子）、`雷霆`（电弧）。

## 正片里怎么用

- 画面：`<法术演出 id="soul_bolt" 秒={出手后的秒} 起点={…} 目标={…} 种子={…} />`（`注册表.tsx`），放在场景坐标（Z 朝上）的 group 里；`[0, 长秒)` 之外自己不画。
- 段.ts（纯）：`取法术元(id)`、`有法术演出(id)`、`法术元表`（`元表.ts`）；`法术时长(元, 起点, 目标)`、`法术声音时刻(元, 起点, 目标)`（`接口.ts`）给出这一发几时命中、各声音落在出手后第几秒。

## 定了的做法和原因

- 不自动扫目录：`import.meta.webpackContext` 只许在作品的 `注册.tsx` 里用（指纹要静态跟到每个文件），所以各组各一份分表，`元表.ts`、`注册表.tsx` 汇总。
- 元数据和组件分两个文件：段.ts 是纯模块，引不了带 `asset:` 的画面文件。
- 画面只管「出手后」：举杖蓄力、杖头聚粒子、施法者身上的东西不在这里（那是亚波伦施法姿势那块的事）。配下界魔杖变样的（`../说明.md` 的表）按变样后的做，别的档（不洁套装、晋升光环）不算。
