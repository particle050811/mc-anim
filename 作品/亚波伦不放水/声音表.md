# 《假如下界亚波伦不放水》声音表

正片要用的声音，按「谁发的」列。这里列的资产都已登记（11-10 逐个对过两张音效表和配乐表，没有缺的，这次没新增资产）；带「私有」的字节不进公开包。
本表主要说「游戏里这个时候响的是什么」和「资产 id 是什么」；已经排进片子的（11-11 起：配乐、环境垫底，第 4、5 幕音效）在第 6 节写了用在哪、多响。各幕音效卡在哪一刻由各段的 `段.ts` 定。混音规矩不在这里，没动。

## 0. 怎么读

- **id 的写法**。表里为了短：
  - 「本 `goety.x`」= `音效/诡厄巫法/goety.x`（Goety 本体，作品表 `资产表/音效.toml`，配方「亚波伦法术音效」）
  - 「原 `entity.x`」= `音效/entity.x`（原版，共用表 `assets/registry/音效.toml`，配方「音效」）
  - `.1`～`.3` = 这个声音事件有 3 个文件，一个文件一件资产（`…x.1`、`…x.2`、`…x.3`），游戏里每次随机挑一个；没有序号的只有一个文件。
- **每个事件的音量、音高、权重**（sounds.json 里写的）在配方暂存目录 `<数据根>/run/extract/亚波伦法术音效/src/音效/诡厄巫法/游戏音效.json`，没登记成资产。代码里 `playSound` 传的音量和音高这次没抄。
- **法术那张表怎么来的**：脚本用 javap 扫每个法术类（连父类）和它放出来的实体类，把各方法里引用到的声音事件按方法分栏。是静态扫描，**没逐个读分支**：一栏里有几个事件的，可能是不同变体、不同档位（比如使徒档、红石变体、落在水里）各用一个，不是都响。「没读到」= 这一栏扫不到事件，多半是游戏里就没有，少数可能藏在没扫到的辅助类里。
- 还缺一个法术声音要补（比如细读后发现漏了）：本体的在 `sourcing/extract.toml` 的「亚波伦法术音效」步骤里加一行 `goety:<事件>`，跑 `anim --作品 亚波伦不放水 extract 亚波伦法术音效 --登记`；原版的跑 `anim --作品 亚波伦不放水 extract 音效 --新 音效/<事件>[.<序号>] --登记`。

## 1. 段里怎么播一个声音

全文见 `docs/新段.md`，现成的例子是 `作品/把回忆拼好给你/核对/段框架示范/`。要点：

1. 声音只在 `段.ts` 里写一次，按秒（或时间线上的事件名）写，`画面.tsx` 不 import 声音字节：

```ts
// 作品/亚波伦不放水/段/<段键>/段.ts
import { 窗口段 } from '@engine/段/窗口段.ts';
import 线 from './时间线.ts';
import 声音表 from './声音表.生成.ts';

export default 窗口段(线, {
  起: '开场',
  止: '收尾',
  声音表,
  声音: ({ 放, 事件 }) => [
    // 放(资产 id, 哪一刻, 目标)：目标写数字 = 把这个文件的采样峰值放到多少 dBFS
    放('音效/诡厄巫法/goety.master_fang_telegraph.1', 事件.撕咬起手, -14),
    放('音效/entity.evoker_fangs.attack', 事件.撕咬咬合, -10),
    // 也可以写 { 峰值 } / { 响度: LUFS } / { 增益: 倍数 } 三选一，外加 名、入点秒、淡出秒、速率、档
    放('音效/item.totem.use', 事件.图腾, { 峰值: -8, 名: '图腾' }),
    // 私有的（启示录、结算曲）照样按 id 写，不打进包，数据根里没有就是静音
    放('配乐/亚波伦/決戦の刻', 0, { 入点秒: 0, 响度: -20, 名: '战斗曲', 淡出秒: 0.5 }),
  ],
});
```

   上面的事件名、分贝数都是示意，不是定下来的数。
2. 跨好几段的声音（战斗曲、结界嗡鸣、循环的氛围声）写在场时间线上：`定义场时间线({ 场, 事件, 声音: [{ 资产, 名, 在, 止, 循环, 响度, 淡出秒 }] })`；`循环` 必须给 `止`。
3. `画面.tsx` 用 `定义画面(段, 声音地址, 组件)`，声音自动放，不用自己写 `<Audio>`。
4. 加了、改了声音以后跑 `anim --作品 亚波伦不放水 cues`，生成 `声音表.生成.ts`（时长、峰值、响度）和 `声音地址.生成.ts`，这两个文件进 Git、不手改；`anim check` 发现没跑会报「跑 anim cues」。
5. 一个事件有几个文件的（`.1`～`.n`）要自己点名用哪一个；框架不替你随机。

### 6.2 第 4、5 幕的音效（11-11，Agent 取的，用户没听过）

用户 11-11「为什么没有声音啊？那个法术不是有音效吗」，看五版又说「然后还有那个音乐和放法术的音效你都得加上啊」。写在 `段/4-齐放/段.ts`、`段/5-击败/段.ts`，71 个法术的在 `场/1-台地/齐放声.ts`；时刻都从 `场/1-台地/齐放拍.ts`、`击败拍.ts` 导出的拍子和法术自己的出手表取（法术的声音照游戏里那一刻），`场/1-台地/齐放击败.test.ts` 核卡点。响度同第 6.1 节：主要峰值 −10 dBFS、次要 −18 dBFS。下面的秒是幕内秒（第 4 幕从 0:16.2 起，第 5 幕从 0:27.45 起）。挑哪几个、哪个算主要都是 Agent 取的。

**71 个一起响怎么不糊**（`齐放声.ts`，第 4 幕 274 条 cue 里 232 条是它出的）：

1. **施放声每个都有**：70 个法术各配一条游戏里起手那一声（`法术/施放声.ts`，照第 2 节「施放声」一栏），第 71 个结界（炼狱）的施放声就是开头张盘那一声。游戏里读不到施放声的 6 个换成同学派的起手声（雷暴 zap、水蛭 prepare_summon、水柱和卫射 abyss_prepare_spell、霜呼 frost_prepare_spell、虫群 wild_prepare_spell）；凋灵寂灭的 quietus_beam 是启示录的私有音效，公开构建打不进包（私有的只有配乐能按 cue 现取），换成凋灵射击。
