# 娘化亚波伦（YSM 版）：骨骼和现成动作

声明在 `娘化亚波伦.tsx`，核对段是 `核对-娘化亚波伦`（`核对/娘化亚波伦/`）。来源：作者 4911 的 YSM 玩家模型包「使徒娘化版」，GPL v3，jar id `ysm-使徒娘化`。358 根骨骼、568 个方盒，贴图 512×512。骨骼名、轴心（像素，模型坐标）都照包里的 `models/main.json`。

## 用法

```tsx
<娘化亚波伦 pose={{ loc, yaw }} 秒={秒} 表演={悬停} 变体={{ 面纱: '加' }} 姿势={{ RightArm: { rot: [-90, 0, 0] } }} />
```

- `表演`：`定表演({ 主: (秒) => 层们, 环境: (秒) => 环境 })`，在模块里建一次。现成的有 `站立`（idle）、`悬停`（fly）。
- `姿势`：手摆的骨骼姿势，盖在动画上面。施法、开轮盘靠它。
- `持杖`：右手拿下界魔杖（`物品/下界魔杖.tsx`，挂在 `RightHandLocator`）。定位骨之后怎么摆 YSM 在原生库里核对不了，照同作者开源的车万女仆写的（推断）：手臂垂着时杖头朝前，握点在杖身正中。`idle` 里杖横在身前；`fly` 里两手合在胸前，杖会穿过脸，飞着持杖要用 `姿势` 另摆右臂（`RightArm`、`RightForeArm`）。
- 缩放 0.7/16（`ysm.json` 的 `height_scale`、`width_scale`）。站着帽顶约 2 格，头后大光环顶约 3 格，蜘蛛腿左右各伸出约 1.7 格。

## 贴图和面纱

五张贴图同一套 UV。面纱、光环、蜘蛛腿显不显，只看贴图上那块有没有像素，没有变量管。

| 贴图 | 衣边 | 面纱 | 帽上红色漩涡光环 | 蜘蛛腿、浮块、头后眼形大光环 |
|---|---|---|---|---|
| `default`（本片默认，下界二阶段） | 红 | 无 | 无 | 有 |
| `2default` | 红 | 有 | 有 | 无 |
| `3default` | 金 | 无 | 有 | 无 |
| `4default`（包的默认，作者视频封面） | 金 | 有 | 有 | 无 |
| `5default` | 红 | 无 | 有 | 无 |

- 面纱是骨骼 `bone25`（帽子 `mao` 下面，三片：脸前、脑后、右侧），UV 在 (218,339)～(241,372)。
- 漩涡光环是 `ysmGlowbone185`（挂在 `bone186` 下，`parallel0` 让它斜 45 度、每秒转 36 度），UV 在 (192,0)～(256,64)。

## 结算舞「忘情牛肉面」（手做，`动作/忘情牛肉面.ts`）

用户 11-09 定用这支。照参考视频 08（真人全身正面，9.36 秒）每 0.25 秒抽帧看着摆的，姿势是估的，不是动作数据。核对段 `核对-结算舞`（前 10 秒灰底，后 10 秒教堂跳舞位）。

```tsx
const 跳舞 = 定表演({ 主: () => [{ 名: 'idle' }], 环境: 忘情牛肉面环境 }); // 模块里建一次
<娘化亚波伦 pose={…} 秒={秒} 表演={跳舞} 姿势={忘情牛肉面姿势(秒)} />
```

- `秒` 就是 08 的秒数：配乐对上 08 的音轨，拍子就对上。一遍 `一遍秒`（9.36），之后停在站姿；`忘情牛肉面姿势(秒, { 循环: true })` 接着再跳。
- 怎么叠：idle 垫底，舞的姿势按通道盖掉 `UpBody`、`DownBody`、`Head`、两臂两腿共 15 根骨骼的转角；眨眼、浮块自转、蜘蛛腿照旧。头后大光环、浮块挂在 `aaabody` 上，不跟着顶胯、转身。头发、胸部的弹簧吃 `忘情牛肉面环境` 给的转身速度和起落速度，这支舞里只动几度。
- 关键帧表是 `时间线`，每行写了对应 08 的第几秒、是看清的还是估的。姿势写在舞台坐标里（胯挪多少、身子转多少、手臂朝哪、脚踩在哪），腿按脚的落点反解，顶胯时脚不滑。
- 左右：把 08 当成没镜像（画面右 = 她的左手），没法确认；要反过来用 `镜像`。
- 和 08 对不上的：手臂短、帽檐宽，举手的角度都比 08 往外、往前偏，不然手藏在帽子后面；腿在长袍里，提膝、抬脚点地只露出一点；8.0 秒 08 是两脚前后交叉，这里只并拢。

包里另有联动动画（`tac`、`carryon`、`parcool`、`swem`、`slashblade`、`tlm`、`arm`、`fp_arm`），已入库，声明里没接，本片用不到。`controller/main.animation_controllers.json` 的八个控制器全是空状态，不用接。

## 层的顺序和环境

- 顺序：`pre_parallel0～2` → 主动作 → `parallel0～1`（转角相加）。依据是 YSM wiki「并行动画」一页。YSM 2.6.5 的播放器在原生库里，没法对着源码核对；口径用 `'通用'`。
- 受击怎么和主动作让位，没核实；核对段里当成整段换成 `attacked`。
- 环境里给了值的：`q.ground_speed`、`q.vertical_speed`、`q.yaw_speed`、`ysm.head_yaw`、`ysm.head_pitch`、`ysm.elytra_rot_z`，站着都是 0。飞的镜头按时间给：YSM wiki 写飞行时 `ground_speed` 是 20，走约 1.7，跑约 3.2；`vertical_speed` 单位米/秒，朝上为正。
- 包自己没赋值的变量按 0 算：`v.hv`、`v.hg`、`v.bg` 全包没有一处赋值，`v.bv` 只有 `idle`、`walk` 等几段赋。
- 别的动作（游泳、鞘翅、爬梯）还会读 `ysm.head_yaw`、`ysm.head_pitch`、`ysm.elytra_rot_z`，都已给 0。

## 头发、胸部的弹簧（`ysm.second_order`）

- 实现在 `engine/anim/二阶系统.ts`。**定义是推断的**：YSM 的实现在原生库里查不到，wiki 只给了签名 `(name, input, frequency, coefficient, response)`，这里按参数名相同的通行二阶系统写法做。
- 从第 0 秒按 1/60 秒一步推到要的时刻，中途存档，结果只看时间，和取帧顺序无关。`定表演({ 弹簧: '稳态' })` 可以关掉晃动（弹簧直接等于输入）。
- 站着不动时输入是 0，头发不动。水平速度、竖直速度、转身速度、抬头角度变了才会晃：比如 `ground_speed` 从 0 到 20，头发先甩过 20 度再停在 20 度。
