# 在 Blender 调结算舞，再回到 Remotion

Blender 负责人物，Remotion 负责教堂、机位、史蒂夫、声音和合成。交付里的 `亚波伦结算舞.blend` 可以直接打开：真实蒙皮、UV、内嵌贴图和动作都在文件里，不需要 MCP 才能编辑。它是**角色工程**，不是整套教堂场景。时间轴从 0 到 845，60 fps；真人原帧 `n` 对应 Blender 帧 `2 × n`。

## 改一处动作

1. 另存一份 `.blend`。默认已进姿态模式，选中角色本人的 `RightArm`。第 0 帧可直接看起手；第 452 帧是侧身前送，第 482 帧是收到胸前。
2. 在「舞蹈主骨」调手臂和双腿；需要改前襟、裙摆或头饰时，打开骨架数据里的「附属骨 · 展开可编辑」。在动作编辑器或曲线编辑器调关键帧，保存工作副本。原动作已采样到成片帧率，改一颗键通常只影响这一帧；要改一段，选中多帧或用约束驱动后烘焙。
3. 从仓库根目录运行下列命令。示例导出右侧上下臂；使用 IK 时，要列出所有受驱动的原角色骨骼，而不是只填 IK 控制器。

```sh
maker='作品/亚波伦不放水/制作'
blender -b /路径/舞蹈工作副本.blend --python-exit-code 1 --python "$maker/blender_rig.py" -- export /路径/舞蹈修订.json RightArm RightForeArm
node "$maker/导出结算舞.mjs" --check /路径/舞蹈修订.json
node "$maker/导出结算舞.mjs" --import /路径/舞蹈修订.json
./anim --work 亚波伦不放水 still 6-结算舞 0,452,482 --level 预览 --tele '160,170,640' --to-preview 工作-Blender校舞
```

`--check` 不写文件。`--import` 替换整份 `角色/动作/Blender修订.json`，不会把两次补丁自动合并；已有修订时先备份，再从同一工作工程导出要保留的全部骨骼。补丁是父骨局部空间的绝对旋转、位移、缩放。未列出的骨骼保留原舞轨；因父骨运动而跟随移动的子骨、根据舞姿重新避让的衣摆不必逐个打键。

## 从当前正片重新建档

```sh
maker='作品/亚波伦不放水/制作'
target="$(mktemp -d)"
node "$maker/导出结算舞.mjs" "$target/bundle.json"
blender -b --python-exit-code 1 --python "$maker/blender_rig.py" -- build "$target/bundle.json" "$target/结算舞.blend"
```

重建读取当前舞姿（包括已导入的修订）和同一份模型、贴图，另写新档，不要覆盖尚未回输的手改工程。检查无误后仍用 `./anim --work 亚波伦不放水 --low-priority film 1-6 --name 新版本名` 出片。

D 版的两块附加 UV 在原包图外。导出器会把正片实际使用的 768×512 图集编码成 PNG 并嵌入 `.blend`，不能用原包的 512×512 PNG 替换，否则头脸、帽饰和袍纹会丢失。

## 穿模与回输的边界

交付角色保留 358 根原骨骼和刚性权重，宽袖、尖帽、领带不会变成真人的软布。在 Blender 里可从侧面或背面转看、调整附件骨或用 IK 和骨骼约束修正。回输会读取每一帧约束后的姿态；不能用基岩局部旋转、位移、缩放表示的剪切会报告具体帧和骨名。修改模型拓扑、权重、新建骨骼或顶点布料模拟不会通过这条动作通道带回去。调完应再用成片机位检查袖口、领带、膝盖和鞋，而不是以编辑器视口代替验收。
