# 《假如下界亚波伦不放水》素材清单

对照 `分镜.md`（第二稿，6 幕 40 镜）和 `法术/法术表.ts`（有画面的 71 个）盘的：每个镜头要什么素材、资产 id 是什么、还缺什么、哪些是本片原创要自己画。11-09 盘。

## 0. 怎么读

状态三种，一个法术可以同时占几种：

- **已入库**：贴图、模型、粒子定义、声音的字节都登记了（资产表 + 资产锁），可以直接 `资产('<id>')` 引。
- **要写渲染器**：素材齐了，但画法写在模组的 Java 渲染器里，要照源码在 three 里写一遍。表里给出渲染器类名，源码在 goety 2.5.60.6 的 `com/Polarice3/Goety/client/render/`（启示录的在 `com/mega/revelationfix/client/renderer/`）。
- **jar 里没有要自己画**：jar 里没有对应的贴图或定义，形状全是代码算的，或者是本片原创。

资产 id 的约定（本次定的，照 `docs/命名.md` 的「类别/…」）：

| id | 是什么 | 配方（`sourcing/extract.toml`） | 可见性 |
|---|---|---|---|
| `贴图/法术/goety/<textures 下的路径>` | 本体的实体贴图、粒子贴图，路径照 jar | 亚波伦法术贴图 | 提取（MIT） |
| `数据/法术/goety/particles/<粒子 id>` | 本体粒子定义 json（用哪几张贴图） | 亚波伦法术粒子定义 | 提取 |
| `模型/法术/goety/<模型类名>`、`动画/法术/goety/<动画类名>` | 从 Java 模型类读出来的方盒模型、关键帧 | 亚波伦法术模型 | 提取 |
| `音效/诡厄巫法/goety.<事件>[.<序号>]` | 本体声音事件，一个文件一件 | 亚波伦法术音效 | 提取 |
| `贴图/法术/minecraft/<路径>`、`数据/法术/minecraft/particles/<id>` | 库里原来没有的原版贴图、原版粒子定义 | 亚波伦原版贴图、亚波伦原版粒子定义 | 提取（Mojang EULA） |
| `音效/<原版事件>[.<序号>]` | 原版声音，登记在共用表 `assets/registry/音效.toml` | 音效（`--新`） | 提取 |
| `模型/方块/黑暗祭坛`、`贴图/方块/黑暗祭坛`、`贴图/方块/黑暗祭坛.激活` | 暗黑祭坛方块 | 亚波伦黑暗祭坛 | 提取 |
| `音效/启示录/…`、`配乐/亚波伦/…`、`数据/着色器/启示录/…`、`贴图/法术/revelationfix/…`、`贴图/物品/破碎之环`、`数据/法术/goety_revelation/…` | 启示录（All Rights Reserved）里的 | 亚波伦启示录素材 | 私有 |
| `数据/角色/史蒂夫装备/神灵金盔甲网格`、`贴图/角色/史蒂夫装备/{神灵金盔甲,晋升之环}`、`贴图/物品/{神灵金头盔,神灵金胸甲,神灵金护腿,神灵金靴子,晋升之环,断曜流光,断曜流光.图标}`、`模型/物品/断曜流光` | 史蒂夫的装备（启示录，见第 5 节） | 亚波伦史蒂夫装备 | 私有 |
| `配乐/结算舞/DreamFunk忘情牛肉面` | B 站下载的结算曲 | 手工（`assets add`） | 私有 |

表里 `目录/{a,b}` 是同目录的几件，`目录/前缀*`（n 张）是同目录同前缀的 n 件。库里原来就有的原版粒子贴图直接写库里的 id（`贴图/特效/粒子/generic_*` 这类）。

三条要先知道的：

- **声音是超集**。每个法术的声音栏是从法术类顺着源码能走到的全部事件（含使徒档、变体分支、命中各种材质），做的时候按画面挑，不是每个都要响。
- **粒子只入了贴图和定义**。粒子怎么动、多大、什么颜色写在 `client/particles/<名>Particle.java` 里，没有可导的数据，做的时候照类写。其中一批不是贴图片而是程序画的网格（环、球、带子），表里单列「程序画网格的粒子类」。
- **每种声音事件的音量、音高、权重**在配方跑完的暂存目录 `run/extract/亚波伦法术音效/src/音效/诡厄巫法/游戏音效.json` 里，没登记成资产（照共用「音效」配方的先例）。
